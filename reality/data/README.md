# 취업 객관 위치·자신감 회복 공식 통계 데이터셋 (career-reality-stats)

- 버전: **1.0.0**
- 생성일: **2026-11-15**
- 구성: illusion_checks **10개**, segment_filters **9개**, timeline_and_odds **7개 블록**, 출처 **11건**(공식 8건 / 민간 3건)

## 1. 이 데이터셋의 목적과 사용 방식

직업상담 자료실의 신규 독자 섹터 — **내담자의 객관적 시장 위치 확인 + 부정적 취업 착시 파괴 + 자신감·자기효능감 회복** — 을 위한 데이터입니다.

- `illusion_checks`: 내담자에게 슬라이더로 예측값을 먼저 받고, 실제 공식 통계와의 **오차(착시)** 를 보여주는 항목입니다. 각 항목에는 `actual_value`(실제값), `distribution_buckets`(분포 위 내 위치 표시용 구간 데이터), `insight_reframe`(억지 위로 없는 팩트 리프레임), `controllable_action`(통제 가능 변수 1개), `counselor_note`(상담사용 질문·피해야 할 역효과)가 들어 있습니다.
- `segment_filters`: 연령·학력·계열·기업규모·단절 사유 등 **확인된 공식 세부 통계**입니다.
- `timeline_and_odds`: 채용 타임라인(준비기간·채용 소요일수)과 **지원 횟수 대비 합격 확률** 모형입니다. 공식 통계 / 민간 조사 / 수학적 모형을 `evidence_level`로 구분했습니다.

권장 화면 흐름: ① 슬라이더로 예측 → ② 실제값과 오차 표시 → ③ 분포 위 내 위치 → ④ 팩트 리프레임 → ⑤ 통제 가능 행동 1개 → ⑥ 상담사 질문.

## 2. 파일 구성

```
downloads/career-reality-stats/
├── reality_stats.json          # 본 데이터셋 (metadata / illusion_checks / segment_filters / timeline_and_odds)
├── README.md                   # 이 문서 (구조·출처·저작권 검수표)
├── build_reality_stats.py      # JSON·README 생성 스크립트 (수치·계산식이 코드로 남아 있음)
└── validate_reality_stats.py   # 필수 필드·범위·합계·출처 참조 검증 스크립트
```

## 3. JSON 구조

### 3.1 `metadata`

- `name` / `name_en` / `version`: 데이터셋 식별자와 버전
- `generated_at`: 생성일(YYYY-MM-DD)
- `purpose` / `intended_use`: 목적과 사용 시나리오
- `counts`: 항목·출처 개수(공식/민간 구분)
- `copyright_and_source_principles`: 수집·인용 원칙 5개
- `disclaimer`: 기준시점·모집단 표시 의무, 예측 아님 고지
- `caveats[]`: 수치 오용을 막기 위한 주의사항(기준시점·분모·모집단·규모 기준·민간 조사)
- `sources[]`: 출처 등록부: `source_id`, `tier`(official/private), `org`, `survey`, `period`, `published`, `url`, `url_report`, `copyright`
- `calculations`: 파생 비율의 값·계산식·주의사항

### 3.2 `illusion_checks[]` 필드

| 필드 | 의미 |
|---|---|
| `id` | 항목 식별자(영문 스네이크케이스) |
| `category` | 분류(일자리 구조 / 청년 이행기 / 거시 고용 / 경력단절 등) |
| `myth_statement` | 내담자가 흔히 믿는 착시 문장 |
| `term_note` | 용어 정의 주의(예: '300인 이상 사업체' ≠ 법정 대기업). 해당 항목에만 있음 |
| `question` | 슬라이더 앞에 제시할 질문 |
| `unit` | % 또는 개월 |
| `slider_min` / `slider_max` / `slider_step` | 슬라이더 범위·간격 |
| `actual_value` | 실제 공식 통계 값(숫자) |
| `actual_label` | 실제값의 서술형 표기(기준 포함) |
| `distribution_buckets` | 분포 막대/곡선용 구간 데이터 `[{label, value}]` |
| `distribution_kind` | `partition`(합 100) / `comparison_group`(비교군) / `none` |
| `insight_reframe` | 사실 기반 인지 리프레임(억지 위로 금지) |
| `controllable_action` | 내담자가 통제할 수 있는 행동 1개 |
| `counselor_note` | `{questions[], avoid}` — 상담 질문과 피해야 할 역효과 위로 |
| `source` | `{source_id, org, survey, period, url, copyright_note, evidence_level}` |
| `calc_note` | 파생값이면 계산식·주의사항 |

### 6.1 지원 횟수 대비 합격 확률 모형

모형: `P(최소 1회 합격) = 1 - (1 - p)^n` (회당 합격확률 `p`, 지원 `n`회, 독립 가정)

| 지원 횟수 n | p=0.020 | p=0.050 | p=0.100 | p=0.245 |
|---|---|---|---|---|
| 5 | 9.6 | 22.6 | 41.0 | 75.5 |
| 10 | 18.3 | 40.1 | 65.1 | 94.0 |
| 20 | 33.2 | 64.2 | 87.8 | 99.6 |
| 30 | 45.5 | 78.5 | 95.8 | 100.0 |
| 50 | 63.6 | 92.3 | 99.5 | 100.0 |
| 100 | 86.7 | 99.4 | 100.0 | 100.0 |

필요 지원 횟수(50% / 80% 도달):

| 회당 합격확률 | 50% 도달 n | 80% 도달 n |
|---|---|---|
| p=0.020 | 35 | 80 |
| p=0.050 | 14 | 32 |
| p=0.100 | 7 | 16 |
| p=0.245 | 3 | 6 |

> `p=0.245`는 고용센터 구직 1건당 취업 성사율(2025년 24.5%)을 참고값으로 넣은 것이고, 나머지는 대조용 가정값입니다. **이 표는 공식 통계가 아니라 수학적 모형**이며, 지원 간 독립 가정은 실제보다 낙관적입니다.

## 9. 한계와 주의

- **기준시점 혼합**: 청년 고용률은 연간 45.0%, 5월 부가조사 46.2%, 12월 44.3%로 다릅니다. 화면에는 기준시점을 반드시 표시해야 합니다.
- **분모가 다른 지표**: 고용률(인구 대비)과 실업률(경제활동인구 대비)을 같은 축에 놓으면 안 됩니다. `calculations.youth_employment_rate_denominator` 참조.
- **모집단 차이**: 사업체노동력조사(사업체 종사자 2,020.5만명)와 경제활동인구조사(취업자 2,876.9만명)는 모집단이 달라 비중을 서로 바꿔 쓰면 안 됩니다.
- **민간 조사 의존 항목**: 기업 규모별 채용 소요일수(S10)와 채용 방식 비중(S11)은 공식 통계가 아닙니다. 상담에서는 ‘참고값’으로만 말해야 합니다.
- **구축하지 못한 항목**: ① 청년 첫 직장의 ‘1년 이내 퇴사율’을 근속기간 구간별로 보여주는 공식 공표표는 확인하지 못해, 대졸 유지취업률(81.8%)·1년 내 일자리 이동률(17.8%)로 대체했습니다. ② 기업 규모별 ‘채용 소요기간’ 공식 통계는 확인되지 않아 민간 데이터로 대체했습니다. ③ 30대·40대 경력단절(남성 포함) 재취업 통계는 이번 조사 범위(19~54세 여성) 밖이어서 넣지 않았습니다.

## 10. 상담 사용 시 안전장치 (설계 의도)

- 모든 `insight_reframe`은 **나쁜 소식도 지우지 않는** 방식으로 썼습니다(예: 청년 고용률 하락 3년 연속, 임금 격차, 경력단절 7.5년). 위로를 위해 수치를 희석하면 내담자가 나중에 배신감을 느낍니다.
- `counselor_note.avoid`에는 ‘~해도 괜찮아요’식의 일반론 위로, 지표를 반박하는 방식, 낙인 표현을 금지 사항으로 적었습니다.
- 통제 가능 변수는 항상 **1개**로 제한했습니다(여러 개를 주면 자기효능감 대신 압박이 됩니다).
