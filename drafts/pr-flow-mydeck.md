27번 독립 섹터 **「상담 플로우 아키텍트」**(알고리즘 트리형 덱 빌더)와 로그인 사용자의 **「마이덱」** 별도 화면, **공간 꾸미기(6요소 × 6조건 + 팔레트·컬러피커)** 를 함께 넣습니다.

## 1. 27번 섹터 `/flow/` — 시너지 결정 트리

- `assets/tools.js`에 `no:'27'`, `mode:'match'`(매치 실무 끝)로 추가. `assets/brand.css`에 `--tc-flow`(밝게 `#3d3a72` · 세피아 `#3a3770` · 어둡게 `#a5a8ff`, 본문 바탕 대비 8.4~9.5:1)와 `body[data-jc-tool="flow"]`, 대문 문장 내비 문구 한 줄.
- **키워드로 시작**: 시작 키워드 26개(경력단절여성·경단녀·국민취업지원제도·구직급여·직무분석·법령·면접·자격증·신산업 …)와 직접 입력. 고르면 「이 자료가 무엇이며 뭘 설명하는지」(자료의 실제 소개·meta)를 먼저 보여 주고 `여기서 시작`으로 트리를 연다.
- **트리 가지치기**: 고른 자료마다 다음 후보가 카드 가지로 뻗는다(노드·연결선, 좌측 세로 줄기 + 가지 연결선). 후보마다
  - `근거` — 자료실 연결 짝(`JC_LINKS`)인지, 두 자료가 **함께 쓰는 말**(겹치는 말 N개 · 예: 구직급여, 실업급여, 쉬었음)
  - `N개 연결 — 함께 쓰는 것` — 앞 자료의 meta + 이 자료의 meta
  - `이어서 할 일` — 자료 장부의 `gi`
  - `흐름 전체` — 흐름에서 **두 쌍 이상** 되풀이되는 말
- **언제든 확정**: 2·3·4개 어디서든 「이대로 만들어볼래요」 → 덱 시트(이름·순서·덮는 범위·**리허설**·**실행 미리보기(자료별 링크)**·저장·시드·매치 덱으로 보내기).
- **적정선 제지**: 6개를 넘기려 하면 「내용 혼재 및 과다 정보예요. 핵심 흐름만 남기는 걸 권해요.」를 토스트 + 인라인으로 띄우고, 「그래도 넣기」를 눌러야 한 개 더 들어간다(상한 8).

### 시너지는 지어내지 않습니다 — `flow/data/graph.json`
`ops/scripts/build_flow_graph.py`가 `assets/tools.js`(장부) · `assistant/data/rag-preface.json`(자료실 지도 키워드·용어표) · `translator/data/terms.json`(용어 1,813개의 연계 섹터)만으로 **짝 164쌍**(연결 짝 50 · 겹치는 말만 114)을 결정론적으로 만듭니다. 근거가 0인 조합은 싣지 않습니다. 화면은 그 칸(제목·딱지·소개·meta·겹치는 말)을 늘어놓을 뿐 문장을 새로 쓰지 않습니다.
겹치는 말은 **드문 말 → 근거 종류(지도 키워드 > 용어표 > 번역기 > 섹터 검색어) → 한글** 순으로 골라 「AI」 같은 흔한 말이 근거처럼 보이지 않게 했습니다.

## 2. 마이덱 `/mydeck/`

- **계정 팝업(`assets/sync.js`)에 「마이덱」 메뉴** 추가 → 별도 페이지로 이동.
- 저장한 덱 **목록** — 이름·단계 수·저장 위치 · 자료 **순서대로 열기**(번호 매긴 링크) · **리허설**(한 단계씩) · **이름 바꾸기** · **삭제**. 이 기기에만 있는 덱은 로그인 상태에서 **계정으로 옮기기**.
- 로그인 상태·저장 위치를 화면 위에 그대로 적습니다(로그인/이 기기에만, 함수 미배포 시 안내).

## 3. 공간 꾸미기(DIY) — 6요소 × 요소마다 6조건

| 요소 | 조건 6 |
|---|---|
| 배경 색·톤 | 6 팔레트 + **자유 색상표(`input type=color`·HEX)** |
| 글자 색 | 6 팔레트 + **자유 색상표** + **대비 경고**(WCAG, 4.5:1 미만이면 알림) |
| 덱 카드 스타일 | 기본 종이 · 마스킹테이프 · 클린 보더 · 글래스 · 터미널 · 네온 |
| 서체 분위기 | 기본 고딕 · 세리프 명조 · 코딩 모노 · 에디토리얼 믹스 · 둥근 톤 · 고대비 볼드 |
| 배치·밀도 | 2열 카드 · 1열 리스트 · 가로 레일 · 컴팩트 타일 · 여유 보드 · 타임라인형 |
| 장식·강조 | 번호 뱃지 · 연결선 강조 · 그림자 깊이 · 좌측 컬러바 · 이모지 태그 · 미니멀 |

- **밝게·세피아·어둡게 테마마다 따로 저장**하고, 고르는 즉시 덱 공간에 반영됩니다(공간 요소의 `data-diy-*` + `--d-bg`/`--d-ink` 두 변수만 바꾸고 파생 색은 `color-mix`). 오른쪽 위에 「저장 · 이 테마 되돌리기 · 세 테마 모두 초기화」.
- 휴대폰은 요소를 하나씩 골라 보는 단계 칩으로 줄여 세로 길이를 줄였습니다.
