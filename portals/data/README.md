# 고용 사이트 안내판 데이터 (job-portals-directory v1.3.0)

직업상담 자료실(`ccttsi/jobcounsel`)의 **32번 「고용 사이트 안내판」** 이 쓰는 데이터셋입니다.
클로드가 사이트를 지어내지 않고, 실제로 접속해 확인한 사이트만 안내하도록 만들었습니다.

- 만든 날: 2026-11-16 · **1.1.0: 2026-11-19** · **1.2.0: 2026-11-24(고용 사이트 안내판으로 확대)** · **1.3.0: 2026-11-24(제외 20곳 실측해 16곳 추가)**
- 수록: **107곳** — 공공·공무원·공기업 8 · 공시·기업정보 13 · 민간종합·대기업 15 · IT·테크 12 · 경력·헤드헌팅 5 · 산업별 8 · 대상·근무형태 17 · 직업훈련·자격·평생학습 12 · 고용·노동 행정·지원 13 · 직업·진로 정보·통계 4
- 접속 검증: **107곳 전부 HTTP 200(또는 그에 해당하는 실제 화면)** — 83곳은 `curl`(데스크톱·모바일 UA)로, 22곳은 실제 브라우저로 첫 화면 메뉴와 운영 기관을 확인했다. 2026-11-23에 수록 91곳을 전수 확인했고, 2026-11-24에 1.2.0에서 제외했던 20곳을 다시 열어 16곳을 더했다.
- 제외: 18곳(폐쇄·시간 초과·도메인 판매·TLS 오류·접속 차단·주소 이전) — `meta.verification.excluded`에 사유와 함께 남김

## 2. 무엇을 담지 않았나 (저작권 원칙)

- 공고 본문·공시 자료·채용 문구·슬로건·로고·이미지를 **옮기지 않았습니다.** 이름, 공식 주소, 운영 주체, 그리고 자료실이 직접 쓴 특징 요약(`strengths`)·볼 수 있는 것(`shows`)·활용 팁(`tips`)만 있습니다.
- 공시·기업정보 사이트는 **공식 원문으로 보내는 링크**만 둡니다. 공시 자료를 복제·가공해 싣지 않고, 크롤링·재배포를 막는 약관이 있거나 분쟁이 있는 민간 데이터베이스(크레딧잡·혁신의숲·더브이씨 등)는 넣지 않았습니다.
- 화면도 사이트의 UI를 모방하지 않습니다(`DESIGN.md` §0). 흔한 UI 관습(탭·아코디언·시트)만 씁니다.
- 사이트의 **공고 수·평점·채용 중 여부**처럼 수시로 바뀌는 값은 넣지 않았습니다. 맞지 않는 값이 쌓이면 상담에서 그대로 잘못 쓰이기 때문입니다.

## 3. 접속 검증 방법

1. `curl` GET, 리다이렉트 추적, 데스크톱·모바일 UA 두 가지로 요청 → **최종 응답 200** 확인.
2. 200이 아닌 곳은 사이트 성격을 확인:
   - `403`(자동 접속 차단): 실제 브라우저로 접속해 화면이 뜨는지 확인 → 뜨면 수록(`verify_method: "browser"`: 캐치·인디드·잡플래닛·로켓펀치·넥슨·KIND), 막히면 제외(로버트월터스·우아한형제들).
   - 첫 화면이 스크립트로만 그려져 `curl` 본문에 메뉴가 없는 곳: 실제 브라우저에서 첫 화면 메뉴와 운영 기관(바닥글)을 확인하고 `browser`로 적는다. Q-Net·NCS·고용노동부·복지로·4대사회보험·최저임금위원회·정부24·한국고용정보원·경기도일자리재단·한국데이터산업진흥원·근로복지공단·대한상의 인력개발사업단·능력개발교육원이 이 경우다.
   - 시간 초과·TLS 오류: 응답 본문까지 확인. 도메인 판매 페이지로 바뀐 곳(호텔잡 .co.kr 등)은 **폐쇄로 판정**하고 제외.
3. **해외·클라우드망에서만 차단되는 국내 정부 포털**은 200을 확인했다고 적지 않고 `verify_method: "official"`·`http_status: null`·`verify_note`로 근거와 제한을 남깁니다(화면은 카드에 「국내 접속」). 2026-11-19에 이 등급이던 클린아이·잡플러스·지방자치단체 인터넷원서접수센터 3곳은 2026-11-23 재확인에서 실제 브라우저로 화면이 열려 `browser`·200으로 기록을 올렸고, 지금은 이 등급을 쓰는 항목이 없습니다.
4. 검증일은 항목마다 `verified_at`에, 제외 사유는 `meta.verification.excluded`에 남겼습니다.

### 한계

- 접속 검증은 **사이트가 살아 있는지와 첫 화면에 무엇이 보이는지**만 확인합니다. 각 사이트의 공고 품질·최신성·회원 정책은 확인하지 않았습니다.
- 2026-11-23 재확인에서 당시 수록 76곳(1.2.0 이후 91곳) 전부 직접 응답(또는 브라우저 화면)을 봤습니다. 2026-11-19에 `official` 등급이던 3곳도 그때는 브라우저로 열렸으므로, 다음 갱신에서 다시 막히면 같은 기준(공식 공표로 주소 확인 → `official`·`http_status: null`·`verify_note`)으로 되돌립니다.
- 지역 일자리포털은 서울·대구·경기만 확인해 넣었습니다(다른 시·도 포털은 도메인 구조가 제각각이라 확인되지 않았습니다).
- 널스잡·블라인드 하이어·고용형태공시 홈페이지는 상담에서 자주 언급되지만 접속이 확인되지 않아 **뺐습니다.**
- 법조·호텔·관광·물류·해운 분야는 살아 있는 전문 사이트가 확인되지 않아 해당 분야는 종합 사이트로 대체했습니다.
- 늘배움(`lifelongedu.go.kr`)은 TLS 인증서가 `*.all.go.kr`로 발급돼 브라우저에서도 열리지 않아, 사이트가 살아 있어도 넣지 못했습니다.

## 4. 갱신 절차

1. `portals.json`을 고친다(항목 추가·주소 변경·폐쇄 제외).
2. `validate.py`의 `EXPECTED`(총 건수·대분류별 건수)와 `ALLOWED_DATES`·`VERIFIED_AT`를 함께 고친다.
3. `SCHEMA.md` §3의 대분류별 건수 표와 이 문서의 실측 수치, `assets/tools.js`의 「사이트 N곳」 표기를 맞춘다.
4. `python3 portals/data/validate.py` → **오류 0건** 확인.
5. `verified_at`은 **그 항목을 실제로 확인한 날**로 적는다. 전수 재접속을 하지 않았다면 날짜만 올리지 않는다.
