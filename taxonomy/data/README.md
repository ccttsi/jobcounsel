# 18. 직업·직무 3대 분류 교차 사전 — 데이터

NCS(국가직무능력표준) · KECO(한국고용직업분류) · KSCO(한국표준직업분류)를 한 파일에서 잇는 교차 데이터셋이다.
화면(`/taxonomy/`)은 이 파일을 정적으로 읽어 계층 탐색·검색·역추적을 하고, 데이터는 여기서 더 늘리지 않는다.

- **데이터 파일**: [`taxonomy.json`](taxonomy.json) — 3.6MB, UTF-8 / [`ksa/index.json`](ksa/index.json) + 샤드 24개 — 30MB, 대분류별 지연 로드
- **인사이트 인덱스**: [`insights/`](insights/) — 화면 맨 위 「한눈에」 카드(한 줄 정의·KSA 성향·키워드)와 면접 예상 질문의 원천. `python3 taxonomy/data/build_insights.py`로 원자료에서 다시 만든다(계약은 SCHEMA.md §9)
- **스키마 계약**: [`SCHEMA.md`](SCHEMA.md) — 화면 구현 전에 반드시 읽는다
- **검증**: `python3 taxonomy/data/validate.py` → 오류 0건 (2026-11-16 기준)
- **배포**: `https://ccttsi.github.io/jobcounsel/taxonomy/data/taxonomy.json` · `https://ccttsi.github.io/jobcounsel/taxonomy/data/ksa/index.json`

## reading 규칙 3가지

1. `code`는 **문자열**이다. 숫자로 바꾸면 KECO 앞자리 0과 KSCO `A` 계열이 깨진다.
2. 매핑 테이블에는 코드만 있다. 명칭은 항상 분류 트리에서 조인한다.
3. **없는 연결을 만들지 않는다.** 연결이 비어 있으면 "공식 매핑 자료 없음"이지 "관계 없음"이 아니다.

## 한계

- NCS↔KECO 공식 매핑은 소분류 단위로만 있고, KECO 495개 중 144개를 덮는다.
- KECO 세분류 16개는 KSCO 연결이 없고, KONET 직업 393건은 KSCO가 비어 있다.
- 능력단위 146건은 고시 별표에 없어 분류번호 앞 8자리로 이었다(`sub_link: "code"`).
- 원자료 오기 1건을 정정했다(KECO 중분류 11 "인문·사화과학" → "인문·사회과학"). 내역은 `meta.corrections`에 있다.
- KSA는 고시 별표 능력단위 13,296건을 **100%** 덮는다. 원천에 없는 138건은 모두 별표 밖 코드이고, 세분류는 현행 1,096개 전부에 응답이 있다(현행 고시에 없는 13개는 응답 없음).
- KSA 파일은 30MB라 `taxonomy.json`에 합치지 않고 대분류별 샤드로 나눴다. 화면은 능력단위 상세를 열 때만 해당 샤드를 받는다.

자세한 필드 정의와 화면 구현 계약은 [`SCHEMA.md`](SCHEMA.md)에 있다.
