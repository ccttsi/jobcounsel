# 갤럭시 홈 위젯 디자인 개편 — 2026-11-28

태화님 요청: 「심심하다. 애니메이션도 있고 세련·고급·심플하게, 색감 센스 있게」 → 이어서 「더 트렌디하게, GTA6 느낌 나게 세련된 걸로」.

## 탐색한 곳
- (웹 밖) 영화 포스터·극장 간판의 해질녘 하늘. 어두운 위쪽에서 지평선 쪽으로 따뜻한 빛이 번지면, 글자가 놓이는 위쪽은 차분하고 아래만 색이 산다.
- (웹 밖) 스포츠 중계 그래픽·경기장 전광판. 좁고 굵은 숫자 하나가 화면을 장악하고, 단위·설명은 작게 곁에 붙는다.
- (웹 밖) 잡지 표지의 쪽번호 「03 — 09」. 진행 위치를 막대보다 조용하게 알린다.
- Android 문서(AdapterViewFlipper·RemoteViews 허용 뷰·ObjectAnimator). 홈 위젯에서 쓸 수 있는 움직임은 «넘길 때 카드 전환» 하나뿐이라는 제약을 확인했다.

## 추상화한 원리
1. **빛은 바닥에만 둔다.** 그라데이션을 카드 아래 모서리 두 곳에만 번지게 하면, 글자 영역의 대비(흰 글자 / 짙은 남색)가 유지되면서도 화려해 보인다.
2. **숫자 하나가 주인공이다.** 좁은 굵은 글꼴(시스템 `sans-serif-condensed`)로 44sp 숫자를 두고 단위는 12.5sp로 붙인다. 제목은 그 아래 15sp로 둔다. 숫자 → 제목 → 부제의 3단 위계.
3. **영문 표지 한 줄로 결을 만든다.** `BRIEFING`·`EMERGING`을 자간 0.16으로 쓰고, 한글 갈래는 옆에 흐리게 둔다. 장식 없이 리듬만 준다.
4. **움직임은 방향이 없어야 한다.** 앞으로·뒤로 넘김이 같은 애니메이터를 쓰기 때문에, 좌우 밀기 대신 «아래에서 떠오름 + 위로 흐려짐»(transform·opacity만, 들어옴 360ms 감속·나감 180ms 가속)으로 한다. 어느 방향으로 넘겨도 어색하지 않다.
5. **낮/밤 두 얼굴.** 폰이 어두운 모드면 밤(D), 밝은 모드면 새벽 파스텔(F)로 바뀐다. `values-night`·`drawable-night` 자원으로 런처가 알아서 고른다.

## 자체 작성 패턴
- 이름: 노을 바닥 번짐 카드 / 쓰는 곳: `android/app/src/main/res/drawable-night/bg_*.xml`
  - 구성: 세로 그라데이션 바탕 + 아래 모서리 두 곳의 방사형 빛(`gradientRadius 70%p`, 끝은 투명).
  - 브리핑 빛: 분홍 `#FF4F7B` + 주황 `#FF9A3C`. 이머징 빛: 청록 `#16C6D6` + 보라 `#7C5CFF`.
- 이름: 새벽 파스텔 / `drawable/bg_*.xml`
  - 135° 세 색 그라데이션. 브리핑은 복숭아→분홍→라일락, 이머징은 민트→하늘→라일락.
  - 글자는 짙은 잉크 `#1E1A24`.
- 이름: 떠오름 넘김 / `animator/card_in.xml`·`card_out.xml`
  - transform·opacity만 쓴다. 시스템 «애니메이션 끄기»를 켜면 자동으로 0ms가 된다.
- 진행 위치: 쪽번호 `03 — 09` + 132dp 진행 줄(밤은 그라데이션, 낮은 잉크 단색).

## 시안 비교
- A 조판(아이보리·명조) / B 야간 잉크 / C 색면 분할: 밀도·직관성은 모두 충분했다. 태화님이 「더 트렌디하게」를 요청해 셋 다 탈락했다. 다음 변이의 재료로 남긴다(사이트 톤과는 A가 가장 가깝다).
- D 해질녘 시네마 / E 크롬 나이트(검정 + 그라데이션 테두리) / F 새벽 파스텔: 태화님이 «폰 테마 따라 D↔F»를 채택했다. E는 절제미가 좋았지만 선택받지 못해 보관한다.
- 자동 넘김(10초)은 태화님이 «넘기지 않음»을 골라 넣지 않았다.

## 이번 작업에 적용할 곳
- `android/app/src/main/res/layout/widget_root.xml`: 바탕 고정 + AdapterViewFlipper + ◀ ▶ 고정.
- `widget_item.xml`: 카드 한 장.
- `Widgets.kt`
  - `Render.move`: `partiallyUpdateAppWidget` + `setDisplayedChild`로 넘김 움직임만 일으킨다(통째로 다시 그리지 않는다).
  - `CardService`: 카드 목록을 런처에 건넨다.
  - `OpenActivity`: Android 14부터 막힌 «변경 가능 + 암시적» PendingIntent를 피하려고, 명시적 화면을 거쳐 링크를 연다.
- `MainActivity.kt`: 앱 안 미리보기도 위젯과 같은 넘김(ViewPropertyAnimator, transform·opacity).

## 지재권 기록
- 「GTA6 느낌」은 **장르 수준의 분위기**(영화 같은 해질녘 빛, 굵고 좁은 숫자, 밤의 대비)만 원리로 가져왔다.
- 쓰지 않은 것: 그 게임의 로고·전용 글꼴이나 그와 닮은 둥근 극굵은 서체, 포스터 일러스트·콜라주 화풍, 로고 안 색띠 배치, 화면 구성, 문구.
  - 이유: 세 질문 중 1·3번(특정 작품이 떠오르는가 / 출처를 짚을 수 있는가)에 걸린다.
- 숫자 글꼴은 안드로이드 기본 `sans-serif-condensed`(시스템 글꼴)만 쓰고, 글꼴 파일을 넣지 않았다.
- 시안 그림에 쓴 Noto Sans KR·Noto Serif KR·Roboto Condensed(OFL·Apache)는 세션 작업 폴더에서만 썼고 저장소에는 넣지 않았다.
