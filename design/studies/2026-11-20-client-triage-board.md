# 2026-11-20 내담자 응급실 트리아지 배정 보드 (`/triage/`)

## 무엇을 참고했고, 무엇을 참고하지 않았나

- **참고한 것 (원리만)**: 응급실 중증도 분류가 쓰는 두 가지 원리 — ① 번호가 낮을수록 먼저 본다(시간 순서가 아니라 **개입 순서**), ② 같은 환자라도 축이 여럿이면 가장 급한 축 하나가 등급을 정한다. 이 둘만 추상화했다.
- **참고하지 않은 것 (의도적으로 멈춘 지점)**: 특정 분류 도구(KTAS 등)의 단계 이름·정의 문구·색 배합·화면 구성. 단계 이름(긴급 개입·집중 소득·취업지원·맞춤형 취업지원·직무역량·훈련 집중·자립 구직·신속 매칭)과 기준 문장은 **법령·공식 제도 요건에서 새로 썼다**. 색은 적→주황→노랑→녹→청이라는 일반 신호 관습만 쓰고, 값은 우리 토큰(`--l1`~`--l5`)에서 테마별로 파생했다.
- **사실 확인(저작권 우선)**: 기준 중위소득(보건복지부 고시 제2025-135호), 국민취업지원제도 Ⅰ·Ⅱ유형 요건·수당(고용24), 긴급복지 기준(보건복지부), 국민내일배움카드(고용24), 구직급여 상·하한(고용노동부 1350·고용보험법)의 **숫자·요건만** 확인해 다시 썼다. 기관 문서의 문장은 옮기지 않았고, 화면 「기준값·출처」에 기관·기준일·원문 링크·이용 조건을 붙였다.

## 화면에 쓴 원리

1. **입력 → 판정 → 행동을 한 화면에** — 다섯 축(생계·주거 / 심리·건강 / 구직의지 / 소득·재산 / 최근 2년 취업경험)을 왼쪽(휴대폰은 위)에, 판정·우선 배정·오늘 할 일을 오른쪽에 붙였다. 제출 단추 없이 고르는 즉시 다시 판정한다(`sim-hud.md` §1).
2. **숫자를 화면에 같이 둔다** — 판정 이유에 「월 소득 1,200,000원 = 4인 기준 중위 18.5% (60% 3,896,843원)」처럼 계산에 쓴 값을 그대로 적는다. 점수만 크게 보여 주지 않는다(`sim-hud.md` §2).
3. **등급은 색 + 숫자 + 이름 셋으로** — 색만으로 구분하지 않는다. 배지·꼬리표·5칸 띠가 같은 상태를 함께 말한다.
4. **기준표는 접어 둔다** — 5단계 기준표·판정 규칙·출처는 「기준 보기」 세 단추 뒤에 두어 첫 화면을 판정에 쓴다(문서 분량 1280 1.42).
