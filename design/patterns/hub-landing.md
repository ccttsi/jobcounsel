# 패턴 — 대문 · 허브 (hub-landing)

적용: `/`(첫 화면). 섹터를 고르는 화면이므로 **고르는 데 필요한 것만** 남긴다.
공통 원칙·토큰은 `../../DESIGN.md`, 손맛은 `touch-physics.md`를 함께 읽는다.

## 1. 첫 화면의 일

- 첫 화면 안에 **① 이 사이트가 무엇인지 한 줄 ② 섹터로 가는 길 ③ 처음 온 사람을 위한 한 걸음**이 있어야 한다. 그 외는 스크롤 아래.
- 문장 다이얼·히어로 카피는 1~2문장. 자동으로 넘어가며 여러 문장을 보여 주는 방식은 **멈출 수 있어야** 쓴다(일시정지 단추 + 감속 모드에서 자동 넘김 끔).
- **문구 길이 예산(2026-11-17)**: 대문 `NAV`는 섹터마다 「목적어 + 동사」 3~10자와 설명 35~62자(두 마디)로 맞춘다. 넘기면 휴대폰에서 설명이 3~4줄 → 6~7줄로 늘어, 롤링할 때 그 아래 「이 자료 열기」·위치 다이얼·문서 높이가 함께 들썩인다(22·23번이 12자·138자로 이 문제를 냈다). `NAV`에 줄이 없으면 「짧은 이름 + 자료를 펼쳐」와 섹터 소개글 전문이 대신 들어가므로, 새 섹터에는 한 줄을 반드시 적는다.
- **설명 칸은 고정 높이 박스(2026-11-18)**: 문구 길이만으로는 흔들림이 0이 되지 않는다(390에서 3줄 7개·2줄 16개 → 「이 자료 열기」가 27.41px 오르내렸다). `.a-say-sub`를 **제목 1줄 + 설명 3줄 = 4줄 높이(`height:calc(4 * 1.6em)`, em이라 글자 확대를 따라간다)** 로 고정하고, 설명은 `-webkit-line-clamp:3`, 남는 줄은 `justify-content:center`로 위아래에 나눠 앉힌다(2026-11-18 밤 재설계). 높이를 JS로 재지 않는다 — 폴더블·회전에서 다시 재야 하는 값을 만들지 않는다. 1~23번 전부 「이 자료 열기」 Y 변동 **0.00px**(390·1280 × 밝게·어둡게).
- 섹터 수는 코드·문서·문구에 적지 않는다. 화면은 `TOOLS` 배열 길이에서 센다(`data-count`).

## 2. 자동 진행(다이얼)

- 상시 `rAF` 루프 금지. 목표에 닿으면 루프를 끝낸다. 자동 넘김은 `setTimeout` 한 번 + CSS 밑줄(`scaleX`)로 진행을 보인다. (대문 문장 다이얼: 3초 대기 rAF 약 180회 → 일시정지·감속 모드 0회)
- 화면 밖·`document.hidden`이면 진행을 멈춘다. 다시 보이면 남은 시간부터.
- 손으로 넘기면 자동 진행 타이머를 처음부터 다시 잡는다.

## 3. 위치·상태 표시

- **위치 다이얼(반원)**: 자료 수만큼 점을 늘어놓지 않는다. 지금 자리를 꼭대기로 한 **반원 궤적에 ±3칸(모두 7개)**만 띄우고, 나머지는 수평선 아래(수심 밑)로 내려 감춘다. 수평선은 다이얼 아래 1px 선, 그 아래에 `7 / 22` 위치 숫자(tabular-nums)를 작게 둔다. 점은 꼭대기에서 가장 크고 밝으며(scale 1.22·불투명도 1) 가장자리로 갈수록 작아지고 옅어진다(0.87·0.55) — 해가 떠오르는 모양이 상태 표시를 겸한다. 2026-11-17 대문.
  - 자리 계산: `x = clamp(offset, -3, 3) × step`, `y = base + rise × (1 - t²)`, `t = min(1, |offset| / 3)`. 반폭에 맞춰 `step = (폭 - 44) / 6`, 최소 38px(그 아래에서는 한 줄에 7개가 안 들어가니 줄을 바꾼다).
  - 점 단추는 **44×44**(예전 22×44에서 44px 미달 22건이 사라졌다). 궤적 위 배치는 `translate3d`로만 하고, 점 크기는 안쪽 `<i>`의 `scale`로 바꾼다(단추 자체를 `scale`하면 누를 수 있는 넓이가 줄어든다).
  - 감출 때는 `visibility:hidden`(탭 순서·접근성 트리에서도 빠진다) + 투명도 0. 움직이는 동안에만 rAF가 돌고, 자동 넘김이 멈춰 있으면 프레임 0회.
  - 휴대폰에서도 위치 숫자 대신 같은 다이얼을 쓴다(자료가 늘어도 폭이 변하지 않는다). 다이얼과 앞뒤 단추가 한 줄에 안 들어가면 단추 묶음이 다음 줄로 내려간다.
- **상태 점**: `box-shadow` 무한 맥박 대신 같은 색 원이 `scale(1→3)` + `opacity`로 세 번만 퍼지고 멈춘다.
- 색만으로 상태를 구분하지 않는다. 점·숫자·글자를 함께 둔다.

## 4. 초면 절제

- **키워드 칩**: 한 줄 설명은 칩 3개(휴대폰 2개)로. 첫 칩만 강조색. 문장은 펼침 안에.
- **통찰 카드**: 제목 + 상담 질문(행동을 부르는 말)까지만 먼저, 풀이 문단은 「풀이 보기」.
- **이용 안내 한 줄**: 섹터 머리에는 「로그인 없이 사용 · 참고·실습용 자료」 키워드만. 문장은 펼침 안에.
- 휴대폰 첫 화면 본문 3줄, 카드 한 장 80자 권장. 첫 화면 글자 수를 줄일 때는 **실제로 보이는 글자만** 센다(투명 처리된 숨은 글자를 세면 측정이 틀린다 — PR #46에서 796→260으로 잘못 보고했다가 294→281로 바로잡았다).

## 5. 섹터 목록

- 카드 한 장에 이름 + 한 줄 정체 + 키워드 1~2. 설명 문단은 넣지 않는다.
- 큰 화면 2~4단, 휴대폰 한 단. 카드 높이를 맞추기 위해 문장을 늘리지 않는다(빈 공간은 여백으로).
- 순서는 자주 쓰는 것부터. 관리 화면의 사용 기록(`/admin/`의 첫 화면 클릭·체류)을 근거로 삼되, 사용자에게 그 순서의 이유를 설명하지 않는다.
- 첫 진입 경로를 하나 더 둔다(「처음이면: 직업상담 이론부터」). 목록만 있으면 초면은 어디를 눌러야 할지 모른다.

## 8. 도태 (이 유형에서 다시 쓰지 않는 것)

- **상시 rAF 루프로 다이얼 회전** — 대기만 해도 3초에 약 180회. 움직일 때만으로 대체.
- **점 인디케이터를 자료 수만큼** — 넘치면 두 줄이 되거나 잘린다(반원 다이얼로 대체, 2026-11-17).
- **`filter:blur`·`width` 보간으로 원근·진행 표현** — `opacity`·`scaleX`로 대체.
- **자동 넘김을 멈출 수 없게** — 읽는 사람의 속도를 무시한다.
- **「더보기」만 있는 펼침 손잡이** — 무엇이 나오는지 말해 준다.

## 9. 시드·매치 모드 — 대문이 「내 목차 덱」이 되는 전환 (2026-11-17~18, `index.html` · `assets/modes.*` · `assets/deck.*`)

대문을 쓰는 두 가지 방식(훑어보기 ↔ 골라 담기)을 오가게 한 실험. 훑어보기(전체 23)는 그대로 두고, **시드(지식·원리 11) · 매치(현장·실무 12)로 나눠 담는 화면**을 따로 둔다.

- **트리거는 두 화면에 하나씩, 2단(장전 → 발동)**. 1차만 누르고 다른 곳을 누르면 조용히 풀린다(ESC 포함, 9초 뒤 자동 해제).
  - **롤링 화면 — 슬롯 레버**(반원 다이얼 오른쪽). 2026-11-18 실기기 피드백으로 세 번 갈아엎었다.
    - 얇은 회색 T 막대 → 받침 하우징 + 세로 홈 + 샤프트 + 손잡이 공 → **반원 다이얼 오른쪽 끝에 얹힌 측면 하우징 + L자 암**(2026-11-18 밤, 이번).
    - **구조(아래에서 위로)**: 받침판(나사 2개) 0~5 · 황동 기둥 5~34(잉크색 세로 홈 8~32) · **홈을 타는 슬라이더(발)** 25~30 · 가로 깨임 26~31 · 세로 샤프트 28~53 · 손잡이 53~71 — 레버 상자 44×74, y=0이 다이얼 수평선이다. L자는 **기둥의 홈에서 가로로 깨여 나와 오른쪽에서 위로 솓는다**(`.a-lever-arm` 한 덩어리).
    - **옆으로 눕히지 않는다.** 1차 장전은 슬라이더째 5px 치켜올라가고 2° 뒤로 젖혀지며(원점은 홈의 슬라이더), 2차 발동은 L자 암 전체가 **수직으로 18px 내려간다**(발동 20px까지 내려졌다 16px로 되돌아 안착). **크기·높이·그림자를 보간하지 않고 `translate3d`·`rotate`만** 쓴다.
    - **다이얼과 한 몸**: `right:24px`로 다이얼·수평선을 하우징 앞에서 끝내고, 레버를 `margin-left:-24px`로 띄우지 않아 — 수평선과 받침판이 같은 높이에서 만나고, 점의 44px 누름 영역을 가리지 않는다. 바탕 그림자는 레버가 아니라 `.a-slot::after`(수평선 위 고정)이다.
    - 「나누기」 글자표는 지운다(무엇을 하는지 글자로 붙이지 않고 오브제가 말하게 한다). 받침 밑동은 다이얼 수평선과 같은 높이(아래 여백 18px).
    - **장전하면 롤링이 한 칸 뒤로 감긴다**(`nav.spin(-1, 260)`) — 「장전 완료, 당길 준비」가 물리적으로 보인다. 취소하면 한 칸 되돌아온다(`disarm` → `spin(1, 240)`), 발동하면 감긴 한 칸을 풀고 여러 바퀴 돈다(`spin(12, 1200)`).
  - **목록 화면 — 동전**(쪽수 아래). 위에서 본 평면 원 → 면·측벽(4단위, 밀링 홈)·광택을 SVG로 그린 **얇은** 황동 동전. 2026-11-18 밤에 **이중 림(바깥 테 + 안쪽 테) · 12방사 음각 눈금 · 가운데 민트 각인(마름모) · 좌상단 광택 호**로 메달결을 올렸다.
    - **그림자는 코인에서 떼어 바닥면 고정 층으로 분리**(`.a-coin-floor`). 전에는 코인에 붙은 `::after`라 코인이 기울고 날아오르면 그림자도 같이 기울어 따라다녔다(실기기 사진 IMG_7758).
    - 1차에 11° 기울며 3px 들리고 **그림자는 scale .9·opacity .72로 따라 줄어든다**. 2차에 **1,250ms 포물선**(정점 −206px, 회전 1,250°)으로 솟았다 내려오며, **비행 층에 코인과 그림자를 한 벌로** 넣고 같은 keyframe 백분율로 움직인다(정점에서 `scale .55`·`opacity .26`, 착지에서 `scale 1.04`). 둘 다 `transform`·`opacity`뿐이다.
- **발동 뒤 무대 타이밍**: 연출을 먼저 보여 주고 글래스가 온다 — 레버는 1,060ms(바퀴 1,200ms의 후반), 동전은 1,040ms(낙하 후반)에 페이드인. 감속 모드에서는 기다리지 않고 바로 연다.
- **1차 상태는 발동이 지우지 않는다**: `disarm()`은 `armed`만 벗기고 `pulled`는 각자의 타이머가 끝까지 보여 준다(오버레이를 열 때 장전을 풀면서 발동 연출까지 지우던 버그).
- **반원 다이얼도 끌어서 돌린다**: 도트 영역을 좌우로 문지르면(터치·마우스) 문구가 따라 굴러가고, 그 위에서 휠을 굴리면 한 칸씩 돈다. 7px 미만의 짧은 누름은 그대로 점 고르기(끌고 난 뒤의 click은 한 번 삼킨다). `touch-action:pan-y`라 세로 스크롤은 방해하지 않는다.
- **돌림 문구 안내 아이콘**: `↕️` 시스템 이모지는 도태(기기마다 파란 상자로 튀고 인쇄 톤과 멀다). 1.15px 선의 인라인 SVG(위아래 꺾쇠 + 세로선)로 바꾼다.
- 실측(360·390·820·1024·1280·1600 × 밝게/어둡게): 넘침 0·오류 0·44px 미달 0, 다이얼 끌기 120px→6칸, 휠 한 칸, 점 클릭 유지. 발동→글래스 실측 레버 1,060ms·동전 1,040ms, 동전 정점 y 481→294(약 187px 상승) 뒤 낙하.

### 9-b. 무대와 카드 — 「네온 상자」를 버린 재설계 (2026-11-18 CP2)

실기기 사진(IMG_7753)의 문제: 색 테두리 상자에 오프셋 그림자(2000년대 PPT), 시드 슬롯이 카드 밖으로 삐져나감, 매치 카드는 파란 선 하나뿐, 중앙이 텅 빔.

- **시각으로 잡는다**: `setInterval(1초)`로 세던 `dwell`을 버리고 `nextEvenMinute(now)`가 다음 짝수분 정각을 계산해 `setTimeout` **한 번**으로 깨어난다. 깨어난 뒤 3초를 넘겼으면(탭이 잠들었다 깬 경우) 건너뛰고 다음 정각을 잡는다. 실측: 정각 **+0.002초**에 시작.

- **만짐 판정을 만들지 않는다**: 유도는 `hold()`·`userMove`를 건드리지 않는다. `JC_NAV.hintRollBegin()`이 **지금 자리(hintBase)** 만 기억하고 자동 넘김 시계를 멈추며, 프레임마다 `hintRollTo(off)`로 `pos = hintBase + off`, 끝나면 `hintRollEnd()`가 **정확히 hintBase로** 되돌리고 새 간격으로 자동 넘김을 건다(`a-hold` 남김 0). 실측 16.00 → 21.00 → **16.00**, 끝난 뒤 5.2초에 다음 칸이 넘어온다.
- **같은 값을 다시 쓰지 않는다**: `lvSet`은 같은 각도면 즉시 돌아가고, `hintRollTo`는 같은 자리(오프셋)면 `layout()`을 부르지 않는다. 래칫 정지 3.2초 구간의 프레임 비용이 사실상 0이 된다.
- **유도 중에는 설명을 다시 그리지 않는다**: 칸마다 긴 설명·`--acc`(하위 전체 스타일 재계산)·`localStorage` 읽기를 되풀이하면 그 프레임이 20ms를 넘었다(21~22ms × 4장). 문구 줄만 굴리고 설명은 제자리에 두면 **20ms 초과 1장**으로 줄고, 읽던 글도 깜빡이지 않는다.

- **3단 차등**: 평상 1.9초·2박동·1배·1.5px → 장전 0.62초·3박동·2.05배·2.4px → 격발 0.26초·6.5박동·2.6배·2.7px. 색은 `--ecg-a/b/c` 세 정거장(청록 → 황토 → 벽돌)을 지난다 — 두 색만 섞으면 장전 중간이 탁한 올리브가 되고, 어두운 테마에서는 `--a2`가 청록이라 격발이 초록으로 보였다.

## 14. 상담 프리셋 — 덱이 「상담 계획표」가 된다 (2026-11-19, `assets/presets.js` · `assets/deck.*` · `index.html`)

태화님 지시: *"시드는 들어갈 때 이런 정보가 필요하다 하면 목록 프리셋이, 매치는 내담자 유형 이러이러 하다 하면 해당 프리셋이 있게."* 도구 진열이 아니라 **판단·처방 워크플로우**가 보이게 하는 층이다. 개인정보는 받지 않는다 — **유형·상황만** 고르고, 꽂은 순서만 이 기기에 남는다.

### 14-1. 장부의 모양 (`assets/presets.js`)

- `window.JC_PRESETS = {seed:[…], match:[…]}`. 프리셋 하나는 **단계(steps)의 묶음**이고, 단계마다 `k`(2~4자) · `q`(상담사가 먼저 던질 질문) · `c`(판단 체크포인트) · `cards`(섹터 id)를 적는다. 프리셋에는 `w`(언제 쓰나) · `why`(왜 이 조합·순서인가 1줄) · `basis`(이론·현장 근거)가 붙는다.
- 카드는 **id로만** 가리킨다(`no` 금지). 아직 없는 섹터는 `presetLive()`가 조용히 걸러 내므로, 다른 작업이 섹터를 나중에 머지해도 그 카드가 자동으로 따라온다(2026-11-19 산업 온도계처럼).
- 검사: `python3 ops/scripts/validate_repo.py --only presets` — 10개 프리셋·39자리 카드를 섹터 장부와 대조하고, 단계 누락·중복·길이 초과·칸 수 초과를 실패로 잡는다. CI의 `static-checks`에 들어 있다.

### 14-2. 화면 (덱)

- **칩 한 줄**(`.a-pre`): 덱 머리 아래. 「상황 프리셋」/「유형 프리셋」 이름표 + 44px 칩. 한 번 누르면 카드가 단계 순서대로 1번 칸부터 꽂히고, 덱 아래 **진행판**(`.a-flow`)이 열린다.
- **진행판**: 단계 탭(44px, 12px 글자, 5단계까지 390px 한 줄) → 고른 단계의 **질문**(큰따옴표, 14px 800) → **확인**(체크포인트) → **왜 이 순서** → **이론·현장 근거**. 단계를 고르면 그 단계 첫 카드가 꽂힌 칸으로 덱이 내려가 깜박인다.
- **되돌리기**: 「프리셋 풀기」는 적용 직전 배치를 그대로 복원한다(`prev[mode]`). 손으로 꽂거나 빼면 프리셋 표시만 풀린다(배치는 남긴다).
- **개인정보 문구**: 프리셋이 켜져 있는 동안 덱 아래 힌트가 *"프리셋은 내담자 유형·상황만 고릅니다. 이름·연령·연락처는 받지 않고, 꽂은 순서만 이 기기에 저장됩니다."* 로 바뀐다. 이 한 줄이 이 기능의 경계다 — 케이스 기록 기능으로 번지지 않게 여기서 끊는다.
- **높이**: 프리셋이 켜지면 `.a-haspre`가 `--deck-h`를 한 단 낮춘다(390: clamp 176px~, 1280: −50px). 실측 390: 1.14 → 1.40화면, 1280: 1.11 → 1.25화면.

### 14-3. 검증 띠 (`.a-vf`)

- 이용 안내 바로 아래 한 줄: 소인(점선 원 + 체크) + 「값의 출처와 검증」 + 키워드 셋(공식 출처·기준시점 / 지어낸 값 0건 / 자동 검사 통과) + 「검증 방식」. 누르면 **값을 다루는 방식** 시트(`#vfOv`).
- 시트는 **세 규칙 → 자동 검사 3단 → 실제 수치 표 → 이 검사가 하지 않는 것** 순서다. 마지막 절이 중요하다: 숫자의 사실 여부는 자동 판정하지 않고 원문 대조는 사람이 한다는 한계를 먼저 밝힌다. 과장이 아니라 구조를 보여 주는 것이 이 띠의 목적이다.
- 수치는 시트에 **기준일과 함께** 적는다(예: 법전 조문 50개 — 2026-11-17 확인). 숫자가 바뀌면 시트의 「기준」 날짜와 값을 함께 고친다.
- 덱(내 목차) 화면에서는 띠를 감춘다(`:root[data-jc-mode] .a-vf{display:none}`) — 작업 화면의 첫머리를 비우기 위해서다.

## 15. 심전도 좌우 끝 알파 페이드 (2026-11-19 R6, `assets/modes.js` · `assets/modes.css`)

태화님 지시: *"심전도 좌우 끝 투명하게 하고 그라데이션 적절하게 넣어서 디자인 고급화"* → 정정 *"파형 그라데이션이 아니라 투명부분과 본체 사이가 뚝 끊기게 투명이 아니라 점점 투명 후 없어지게"*.

- **색은 건드리지 않는다**: 평상 청록 · 장전 황토 · 격발 벽돌(`--ecg-a/b/c`)의 세 정거장 톤은 그대로 두고 **그린 픽셀의 알파만** 깎는다. 파형 색을 알록달록하게 섞으면 「고급화」가 아니라 장식이 되고, 상태를 읽는 신호(청록 → 황토 → 벽돌)가 흐려진다.

- **한 판의 destination-in**: `ecgPaint()`가 다 그린 뒤 `globalCompositeOperation='destination-in'` + 캐시해 둔 `createLinearGradient`로 168×34 한 판을 채운다(`ecgFadeMask`·`ecgEdgeFade`). 프레임당 추가 비용은 이 한 번뿐이고, 파형·줄기 빛 훑기·천장선·잔불·한붓그리기 모양이 **같은 마스크**를 함께 지난다(모양마다 따로 흐리게 만들 필요가 없다).
- **바닥선도 같이 흐린다**: `.a-ecg-base`(1px 헤어라인)는 정적 `mask-image`로 같은 스톱의 알파를 준다 — 프레임 비용 0이고, 파형만 스며들고 바닥선은 뚝 끊기는 어긋남이 없다.
- **실측**: 캔버스 알파 픽셀 기준 끝 열 **1/255** · 가운데 **255/255**, 이웃 열 최대 단차 **4/255(≈1.6%)** — 어느 열에서도 본체 → 투명이 한 번에 뛰지 않는다. 프레임 간격 p95 **16.7~16.8ms · 20ms 초과 0**(390×844·1280×800 × 밝게/어둡게, 장전·격발 포함), 콘솔 오류 0, 가로 넘침 0. 캔버스↔단추↔행 중심 차 **0.00px**.

## 16. 「목록」 뷰 — 번호와 내용을 같은 줄에 세우고 칸 높이를 고정 (2026-11-19, `index.html`)

태화님 지시: *"롤링 말고 목록쪽 넘버랑 내용이랑 위치 배열이 어긋났어. 수정하고 얘도 내용따라 크기 안변하게 박스처리"*.

- **증상**: 줄이 `flex + align-items:baseline`인데 손맛 층(`.a-no{align-self:center}`)이 번호만 줄 가운데로 띄웠다 — 155px 줄에서 제목과 53px 벌어지고, 설명이 짧은 줄은 아래가 비었다.
- **원리 1 — 같은 칸에서 가운데**: 줄을 `grid-template-columns:auto minmax(0,1fr)`로 바꾸고 **번호와 제목을 똑같이 1행**에 둔 뒤 둘 다 `align-self:center`로 놀인다. 크기가 달라도 같은 칸의 가운데라 중심 차가 **0.00px**(글자 크기 2단계의 반올림 0.01px 포함). flex에서 `align-items:baseline` + 자식 `align-self:center`를 섞는 것이 이 어긋남의 원인이었다 — **정렬은 한 축에서 한 방식으로만** 한다.
- **원리 2 — 내용이 아니라 틀로 높이를 정한다**: 제목 `-webkit-line-clamp:1`, 설명 `line-clamp:2` + `min-height:calc(2 * 1.5em)`. 그래서 설명이 한 줄이어도 두 줄 자리를 지켜 **모든 줄이 같은 높이**(390에서 94px, 글자 크기 1단계 103px · 2단계 113px — 글자 크기에만 따라간다).

- **5줄 상자**: 목록 상자 높이는 첫 쪽 줄 높이에서 **한 번만** 재어 `--row-h`로 못 박는다. 쪽을 넘겨도 목록·쪽 번호의 문서 좌표가 그대로(445.52px · 925.52px)다.
- **실측**: 390×844 · 1280×800 × 밝게·어둡게 × 글자 크기 3단계 = 12조합에서 같은 쪽 줄 높이 동일, 번호·제목 중심 차 0.00px, 상자 밖 넘침 0, 가로 넘침 0, 콘솔 오류 0. 캡처 `downloads/search-v2-2026-11-19/list-final-*` · `live-list-*`.

## 17. 「빠른 검색」 팔레트 — 섹터 문이 아니라 자료까지, 근거와 딥링크를 함께 (2026-11-19, `index.html` · `assistant/search.js` · `assistant/build_index.py`)

태화님 지시: *"메인 화면 검색은 큰제목, 카테고리 네임 같이 위계가 높은 거만 나와. 해커스를 쳐도 안 나와. 검색엔진을 고도화, 정밀화해줘"*.

- **위계는 점수로 만들고, 근거를 화면에 적는다**: 이름 일치 > 이름 앞부분 > 별칭 일치 > 이름 포함 > 대표 브랜드·제품 > 업종 순으로 점수를 매기되, 결과마다 `why`(예: `별칭 “해커스”`)를 함께 돌려주어 화면이 **왜 떴는지** 한 줄로 적는다. 사용자는 순위를 의심하지 않고 근거로 판단한다.
- **섹터 문은 자연히 위로**: 섹터 문서(`sector:…`)의 제목·핵심 낱말이 맞으면 ×1.3 — 별도 「섹터 먼저」 묶음을 만들지 않아도 「자격증」 → 자격증 도감이 1위로 온다.

## 24. 쪽 번호판 = 영화필름 원판(릴) — 1↔끝 원형 루프 · 직접 끌어 관성 롤링 (2026-11-21, `index.html`)

> 같은 날 저녁 §25에서 **1칸 층수 카운터**로 대체됐다(숫자 하나만 보이게·관성 보수화). 여기서 계속 쓰는 것: 끝을 없애는 «세 벌» 트랙과 `cvPos` 하나 · 화살표가 끝에서 돌아가는 규칙 · 번호를 누르면 가까운 길로 · 캐치 영역은 `#listView` 하나 · 끌고 난 `click` 한 번 삼킴.

태화님 지시(사진 `IMG_7836`): *"여기부분 물리작동에 따라 한번에 여러페이지도 넘어갈 수 있게 해줘 잡아끌다가 놓으면 넘어가는 상호작용도. 1페이지에서 좌로 가면 막히는게 아니라 끝페이지로 갈 수 있으면 좋겠어. 심플한 박스 디자인을 넣고 좌우 버튼 움직일 수 있게 하는 것과 별개로 1페이지에서 마지막페이지로 가는게 어색하지 않게 디자인해줘. 영화필름같이 생긴 원판의 사이드에 넘버링이 되어있고 그 일부만 박스에 노출되어서 볼 수 있고 롤링하는 방식. 디자인은 과하지 않게 목록과 통일성을 가지게"*. §23(미닫이 창)을 이어받아 **끝을 없앴다**.

- **끝을 없애는 방법은 «한 벌 더»다**: 목록 트랙에 7쪽을 **세 벌(앞·가운데·뒤) 이어 붙이고**, 위치는 «쪽»의 소수 하나(`cvPos`)로만 다룬다. 0이 1쪽, 6이 7쪽이고 −1도 7쪽, 7도 1쪽이다. 한 벌(n쪽)을 건너뛰는 보정은 그림이 같아 **화면에서 보이지 않는다** — 안착할 때마다 가운데 벌로 되돌리고(`cvSettle`), 끄는 동안에도 한 벌을 넘어서면 좌표와 기준점을 같이 옮겨 끄는 거리가 끊기지 않는다. 화살표는 `cvGoal = round(cvPos) ± 1`이라 1쪽에서 `‹` 면 7쪽, 7쪽에서 `›` 면 1쪽(비활성 상태 없음).
- **번호판도 같은 원판**: 번호를 세 벌 이어 붙여(`… 6 · 7 · 1 · 2 · 3 …`) 가운데 칸이 늘 현재 쪽이 되게 `x = 창폭/2 − (cvPos + n + 1/2) × 칸간격`으로 굴린다. 1쪽에서 `6 7 [1] 2 3`, 7쪽에서 `5 6 [7] 1 2` — 1쪽 옆에 마지막 쪽이 보이므로 «끝에서 처음으로»가 어색하지 않다.
- **원판 곡률**: 칸의 알맹이(`.a-pg-n`)에만 `scale(1 − .075·d)` · `opacity(1 − .24·d)` · `translateY(d²·0.45px)`(d = 창 중심에서 몇 칸). 단추 자체를 `scale`하면 누를 수 있는 넓이가 44px 밑으로 준다(§3 다이얼과 같은 이유, 실측 37px). 창 좌우는 `mask-image` 페이드로, 위·아래는 `mask`로 오린 스프록킷 점(4px 높이·opacity .5)으로 「필름」 결만 남긴다 — 새 색을 만들지 않고 `--panel-soft`·`--line-2`·`--a1`만 써서 세 테마가 같이 따라간다.
- **번호판을 잡으면 그 위에서 필름이 1:1로 굴러간다**: 캐치 영역은 §23과 같이 `#listView` 하나지만, `pointerdown` 대상이 `.a-pg-vp` 안이면 1쪽 = 칸 간격(46px), 목록이면 1쪽 = 목록 폭(390에서 362px). 그래서 작은 창을 46px 끌면 한 쪽이 넘어가고, 목록은 같은 «쪽 비율»로 따라 흐른다(둘 다 같은 `cvPos` 하나). 손가락이 12px 넘게 미끄러져야 끌기로 보고 34%(≈16px)를 넘기면 한 칸은 넘긴다 — 번호를 누르려다 8px 흔들린 손가락이 쪽을 바꾸지 않는다(실측 8px → 그대로 1쪽).
- **누르면 가장 가까운 길로**: 번호를 누르면 `d = mod(목표 − 지금, n)`, `d > n/2`면 뒤로 돈다 — 7쪽에서 「1」을 누르면 6칸 되감지 않고 한 칸 굴러간다. 끌고 난 `click`은 §23과 같이 캡처 단계에서 한 번 삼킨다.
- **보이지 않는 것은 없는 것으로**: 세 벌 중 «가운데 벌»만 `aria-hidden=false`·`inert` 해제, 나머지는 낭독·탭에서 뺀다. 번호판도 창 안 다섯 칸만 `tabindex=0`, 나머지는 `-1`+`aria-hidden`. 그래서 탭 순서는 줄 5개 · 번호 5개 · 화살표 2개 그대로다(실측 `tabbableRows 5`·`pagerTab 7`). 번호에 초점이 오면 그 번호가 가운데로 굴러와 초점 고리가 잘리지 않는다.
- **모션**: 규칙은 §2 그대로 — 트랙 `transform`, 알맹이 `transform`·`opacity`뿐. 레이아웃 값은 프레임마다 읽지 않는다(칸 간격·창 폭은 만들 때와 `resize` 때만 잰다). `will-change`는 원판이 움직이는 동안만 붙이고 200ms 뒤에 뗀다. `prefers-reduced-motion`이면 굴리지 않고 그 쪽으로 바로 앉는다.
- **실측**(390×844 터치·1280×800 마우스, 헤드리스 크롬 — `downloads/` 없이 세션 폴더에서만):
  - 원판 120px 빠른 쓸기 → 1쪽에서 7쪽(6칸 관성), 46px 천천히 → 정확히 1칸, 8px 흔들림 → 그대로.
  - 화살표 1쪽 `‹`→7쪽 · 7쪽 `›`→1쪽, 목록 오른쪽 끌기로 1쪽→7쪽, 7쪽에서 「1」 탭 → 1쪽(한 칸).

태화님 지시: *"전체목록 1에서 좌로 가면 7, 7에서 우로가면 1로 가던 기능 없어짐. 그리고 너무 쉽게 두페이지 넘어감. 사용자 물리 작동에 따라 적당하게 움직이게 미세조정. 그리고 아예 목록을 숫자하나만 보여줄까? 1에서 7가는게 어색하지 않게 디자인도 아파트 층수 표기처럼 하고. 근데 좌우로 움직이게 하고"* · *"보통 스와이프에서는 무조건 1페이지만, 의도적으로 크게 작동했을 때만 2페이지 이상"*.

- **«없어짐»의 정체는 옛 미리보기였다**: 사진의 주소창은 `feat-posting-legal-check` PR 미리보기 — 그 빌드는 §24 이전 커밋이라 `.a-pg-reel`이 없고 `gotoListPage`가 `Math.min(n-1,lp)`로 끝을 막았다. 운영에서 1↔7은 정상이었다. **버그를 쫓기 전에 «어느 빌드를 보고 있는지»를 먼저 확인한다.**

## 9-c. 데일리 브리핑 소식 띠 (2026-11-24, 태화님 지시)

- **자리**: 롤링·전체 목록이 함께 쓰는 무대(`#stage`)에 둔다. 768px 이상은 오른쪽 단 맨 위(통찰 카드는 그 아래로 내려 오른쪽 단 빈 자리를 채운다), 띠 머리 줄은 왼쪽 단 첫 줄(「직업상담사를 위한 …」)과 같은 높이(Δ0.0px). 휴대폰은 문장 다이얼·전체 목록 단추 아래, 통찰 위.
- **모양(2026-11-24 3차, 태화님 「뉴스 채널 느낌, 너무 심심함 · 제목·날짜 줄 없어도 됨」)**: 머리 줄을 없애고 48px 한 줄 띠로. 방송 하단 띠의 **일반 문법만** 추상화했다 — 어두운 띠 + 왼쪽 강조색 표지(신문 아이콘, 오른쪽 끝 12px 비스듬히 잘림 `clip-path`, 브리핑 지면 링크) + 위 2px 강조선 + 테두리 꼬리표(국내/해외) + 강조색 마름모 구분 + 오른쪽 멈춤 단추(세로 칸막이). 특정 방송사의 색(빨강)·로고 상자·자막 배치는 쓰지 않고 자료실 강조색(청록)만 쓴다(§0 지재권). 밝게: 띠 `#1f1b18`·글자 `#fbf7f0` / 어둡게: 띠 `#111827` + 안쪽 1px 선, 표지 `#2dd4bf`. 큰 화면에서는 띠 가운데를 왼쪽 첫 줄과 같은 높이(Δ0.0px).
- **움직임(2026-11-24 고침)**: 처음엔 «한 건씩 4.6초 멈췄다 넘기기 + 바닥 진행선»으로 했으나 태화님 「별로, 방송 하단 짧은 소식처럼 자연스럽게 흘러가게」 → **일정 속도로 흐르는 띠**로 바꿨다. 같은 묶음 두 벌을 잇대고 CSS `@keyframes`가 `translate3d(0→−50%)`를 `linear`로 민다(합성 단계 transform만, JS 프레임 루프 0). 길이는 묶음 폭 ÷ 46px/초로 JS가 한 번 정한다 → 화면 폭과 무관하게 같은 읽기 속도. 묶음이 띠보다 짧으면 같은 묶음을 되풀이해 빈 꼬리를 없앤다. 마름모 구분자는 모든 항목 뒤(`li::after`)에 붙여 두 벌 폭을 정확히 같게 한다(이음매 0.00px). 무한 반복 금지(§2-9) 때문에 **3바퀴(약 2분 반) 뒤 멈추고** 재생 단추로 다시 흐른다. 양 끝은 마스크로 18px·28px 옅게. 띠 왼쪽 여백(14px)은 흐르는 줄(track)이 아니라 창(vp)에 준다 — 줄에 주면 −50%가 7px 어긋나 이음매가 튄다.
- **멈춤**: 멈춤 단추 · 마우스 올림·초점(CSS `:hover`/`:focus-within`) · 손가락을 대고 있는 동안 · 화면 밖 · 탭 숨김 · 모드 시트 · 집중 보기. 감속 모드는 흐르지 않고 띠를 손으로 옆으로 밀어 본다(복제 묶음은 감춤).
- **함정 ①**: 창(vp)을 `overflow:hidden`으로 두면 배포 전 점검(`smoke_test.py` 기초 배치 ①)이 «카드 밖으로 밀린 글»로 잡는다 — 잘라 숨기는 것은 결함으로 본다. 창을 가로 스크롤 상자(`overflow-x:auto`, 막대 숨김)로 두면 설계상 넘침으로 인정되고, 흐르는 중에도 손으로 밀어 지나간 소식을 다시 볼 수 있다. 표지와 창을 음수 여백으로 겹치는 것도 «요소 겹침»으로 걸린다.
- **함정 ②**: 띠 안 링크에 붙는 공용 눌림 효과(`jc-pop`)의 `animationend`가 띠까지 올라와 «다 돌았다»로 잘못 셌다 → `e.target === track && e.animationName === 'tk-crawl'`만 센다.
- **테마별 색·글자 크기(2026-11-24 4차, 태화님 「라이트·세피아·다크마다 색이 다르게 · 글자 크기 키우면 커지게」)**: 띠 색을 `--tk-*` 변수로 묶고 테마마다 바꾼다 — 밝게: 짙은 청록 띠 `#12302c` + 녹슨 주황 표지 `#b4532a` + 호박색 선·꼬리표 `#f0b429` / 세피아(`:root[data-jc-tone="sepia"]:not([data-theme="dark"])`): 에스프레소 `#2a1c12` + 짙은 청록 표지 `#1d6657` + 금빛 `#d4a24c` / 어둡게: 남색 `#0b1324` + 청록 표지 `#2dd4bf` + 시안 선 `#22d3ee`. 띠 위쪽은 같은 색을 14% 밝힌 정지 그러데이션, 위 강조선 3px, 꼬리표는 채운 칩. **크기는 모두 em**(띠 `.a-tk{font-size:15px}` 하나만 px) — 공용 글자 크기(`prefs.js`)는 px 규칙만 키우므로 띠 높이·표지·꼬리표·단추·구분 마름모가 ×1.3까지 함께 커진다(48→62.4px). 함정: `max(11px,.74em)`처럼 px가 섞이면 `prefs.js`가 그 값을 다시 곱해 꼬리표만 두 번 커졌다(18.8px) → em만 쓴다.
- **자리 예약**: 자료를 늦게(`load` 뒤) 받아도 띠 높이(91px)를 처음부터 잡아 아래 통찰이 밀리지 않게 하고, 읽기 실패·카드 0이면 띠를 통째로 감춘다.
