# 패턴 — 모바일 · 태블릿 손맛 (touch-physics)

적용: 모든 섹터(특히 휴대폰·태블릿·폴더블). 다른 패턴 모듈을 읽을 때 이 파일은 항상 함께 읽는다.
공통 원칙·토큰은 `../../DESIGN.md`. 실측 방법은 `.claude/skills/design-lead/SKILL.md` ⑥.

## 1. 손맛 기본 장치 (공용 층)

- **오프셋 그림자 카드**(`.jc-pop`): 들림은 `transform`만, 그림자 값은 즉시 교체. 그림자 자체를 전환하지 않는다.
- **소인**(`.jc-seal`): 첫 h1 옆, 처음 한 번만 scale 모션. 휴대폰에서는 종이 윗가장자리에 반쯤 걸쳐 숫자를 덮지 않게 한다.
- **읽기 진행 띠**(`.jc-track`): 스크롤 `rAF` 묶음 + `scaleX`. 상시 루프 금지.
- **공용 접기**(`JC_FOLD`): 상자는 **즉시** 열고, 안쪽 덩어리만 `opacity 0→1 + translateY(8px→0)`로 30ms 간격 생성(`@starting-style`). 높이·`grid-template-rows`·`max-height` 보간 금지.
- **게이지 밑줄**: 펼친 손잡이 아래 강조색 2px 선이 `scaleX(0→1)`, `transform-origin:0`.
- **꺾쇠**: `rotate` 180°. 글자 대신 아이콘 회전으로 상태를 보여 준다.
- **손맛 포인트는 한 화면 2~3개.** 본문·표·형광펜·포스트잇 구역에는 얹지 않는다.

## 2. 터치 타깃 — 최소 44px

- 누를 수 있는 것(단추·탭·칩·입력·접기 손잡이·닫기)은 **44×44px 이상**. 보이는 크기가 작아도 투명 여백으로 채운다(`min-height` + `padding`).
- 예외: 문장 속 인라인 링크는 줄 높이를 따르므로 44px을 강제하지 않는다. 대신 위아래 문단 여백으로 오조작을 줄인다.
- 서로 붙은 단추 사이 간격 8px 이상. 손가락 두 개가 동시에 닿는 모서리(우하단 도구함)는 12px 이상 띄운다.
- 아이콘만 있는 단추는 `aria-label` 필수. 44px을 채우려고 글자를 키우지 않는다(레이아웃이 커진다).
- **작은 화면에서 단추를 늘리지 않는다.** 단추가 5개를 넘으면 접거나 시트로 모은다.

## 3. 백지 프레임 · 프레임 드롭 방지

순서대로 지키면 프레임이 비지 않는다.

1. **면·컨테이너는 유지하고 내용만 바꾼다.** 넘김 끝에 부모를 `innerHTML`로 갈아엎으면 그리는 동안 1~3프레임이 빈다(실측 33ms 백지 2프레임).
2. **덮고 있는 동안 미리 그리고, 조금 뒤에 걷는다.** 걷는 시점을 2프레임(33ms)에서 120ms로 늘리면 백지 0장.
3. **시계는 워밍업 프레임 뒤에.** 같은 프레임에서 애니메이션 t0를 잡으면 레이아웃·래스터 시간만큼 앞부분이 건너뛴다.
4. **바뀌는 층은 미리 승격한다.** `transform`·`opacity`만 움직이는 요소는 GPU 층으로 올라간다. `will-change`는 움직이는 동안만(수 개), 끝나면 지운다.
5. **그림자는 진행값에서 계산한다.** 애니메이션 중 그림자·필터를 전환하면 매 프레임 래스터가 다시 필요하다.
6. **3D 앞뒷면은 z로 띄운다.** `backface-visibility:hidden`만으로는 0°/180°에서 두 면이 같은 평면이라 깜빡인다(`translateZ(.5px)`).
7. **큰 목록은 한 번에 그리지 않는다.** 쪽 단위로 끊어 그린다.
8. **화면이 가려지는 경우를 대비한다.** `rAF`가 멈추는 탭 전환·화면 잠금에서 남는 것이 없도록 `setTimeout` 안전망을 함께 건다.

## 4. 드래그 · 끌기

- `pointerdown`에서 `setPointerCapture`, `pointermove`는 `{passive:true}`, `pointercancel`·`lostpointercapture`에서 원위치.
- 끌기 시작 임계값 6~10px(세로 스크롤과 겹치는 곳은 세로 우선). 임계값 전에는 아무것도 움직이지 않는다.
- `touch-action`으로 브라우저에 의도를 알린다. 가로 끌기 영역은 `touch-action:pan-y`, 단추·도구함은 `touch-action:manipulation`.
- 관성·스프링은 손맛이 아니라 멀미의 원인이 되기 쉽다. 회전·이동은 짧고 결정적으로, 놓으면 목표 위치에 정확히 선다.
- 끌기 중 스크롤 잠금은 `overflow:hidden` 대신 끌기 영역만 `touch-action`으로 처리한다(본문 스크롤 위치가 튀지 않게).
- 끌기 중 텍스트 선택·이미지 드래그 차단(`user-select:none`, `-webkit-user-drag:none`), 길게 누르기 메뉴가 필요한 곳은 예외.

## 5. Safari · 삼성 인터넷 대응

| 항목 | 대응 |
|---|---|
| `@starting-style` 미지원(iOS 17.5 미만·구형 삼성 인터넷) | 지원하지 않으면 그냥 즉시 보이게 둔다. 폴리필을 넣지 않는다(깜빡임보다 낫다). |
| 100vh가 주소창 때문에 넘침 | `min-height:100vh` + `100dvh` 순서로 겹쳐 쓴다. |
| `backface-visibility` | `-webkit-` 접두어를 함께 쓴다. |
| `:active` 반응이 iOS에서 안 먹음 | 문서에 빈 `touchstart` `{passive:true}` 리스너를 한 번 건다(공용 층이 이미 한다). |
| 누를 때 회색 깜빡임 | `-webkit-tap-highlight-color:transparent` + 직접 만든 눌림(`transform:scale(.98)`, 120ms). |
| 300ms 지연·더블탭 확대 | `touch-action:manipulation`, `<meta name="viewport" content="width=device-width,initial-scale=1">` |
| 안전 영역(노치·홈 인디케이터) | `env(safe-area-inset-*)` — 특히 아래 고정 입력창·도구함. |
| 주소창 접힘/펼침 | 높이는 `resize`·`visualViewport.resize`에서 다시 잰다. 높이를 JS로 고정하지 않는다. |
| 삼성 인터넷 뒤로 가기 제스처 | 화면 가장자리 20px 안에 끌기 영역을 두지 않는다. |
| hover로만 보이는 정보 | hover가 없는 기기에서도 보이게 한다(`@media (hover:hover)` 안에서만 hover 효과). |

## 6. 연속 입력 반응

- 입력 → 화면 갱신은 한 프레임에 한 번으로 묶는다(`rAF` 예약 + 중복 예약 방지). 키 입력마다 DOM을 갱신하지 않는다.
- 읽기(`getBoundingClientRect`)와 쓰기(스타일 변경)를 같은 루프에서 번갈아 하지 않는다. 먼저 전부 읽고, 그다음 전부 쓴다.
- 입력 필드가 있는 화면은 계산을 `requestIdleCallback`이나 60~120ms 지연 후로 미루되, **입력 자체는 즉시** 반응하게 한다(글자가 늦게 뜨면 안 된다).
- 긴 목록 필터는 입력마다 전체를 다시 그리지 않는다. 먼저 줄이고, 보이는 만큼만 그린다.
- 100ms를 넘는 작업(대량 파싱·정렬)은 첫 입력 전에 끝내 둔다. 입력 도중에 하면 타이핑이 끊긴다.

## 8. 도태 (이 유형에서 다시 쓰지 않는 것)

- **높이·`grid-template-rows`·`max-height`로 펼치기** — 매 프레임 레이아웃을 다시 계산해 저사양 안드로이드에서 끊긴다. 상자 즉시 + 내용 떠오름으로 대체.
- **`box-shadow` 무한 맥박** — 배터리·프레임을 먹고 산만하다. 같은 색 원이 3회 퍼지고 멈추는 방식으로 대체.
- **`filter: blur` 전환** — 프레임마다 래스터. `opacity`로 대체.
- **상시 도는 `requestAnimationFrame`** — 대문 다이얼에서 3초에 약 180회 돌던 것을 움직일 때만으로 바꿨다.
- **점 인디케이터를 자료 수만큼 늘어놓기** — 15개에서 이미 한 줄을 넘겼다. `14 / 15` 위치 숫자로 대체.
- **hover에만 정보 두기** — 터치 기기에서 사라진다.
