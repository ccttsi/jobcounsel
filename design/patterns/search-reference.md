# 패턴 — 검색 · 찾아보기 · 법령 리더 (search-reference)

적용: `/law/`(직업상담 법전)처럼 **찾는 화면과 읽는 화면이 한 몸**인 섹터. 목록이 수십~수천 건이고, 항목 하나가 긴 본문을 가질 때 쓴다.
공통 원칙·토큰은 `../../DESIGN.md`, 손맛은 `touch-physics.md`, 쪽 넘김은 `ebook-reading.md`를 함께 읽는다.

## 1. 첫 화면 — 검색 한 칸이 곧 목차

- **큰 검색창 하나 + 상황 키워드 칩 5~6개.** 칩은 「사용자가 실제로 말하는 낱말」로 만든다(법령 이름이 아니라 `소개비`, `수습 해고`). 칩이 두 줄을 넘으면 앞의 5~6개만 보이고 나머지는 검색어 사전에만 둔다.
- **검색창 아래 한 줄에 「전체를 책처럼 보기」 같은 두 번째 입구**를 둔다. 검색으로 못 찾는 사람의 탈출구다.
- **검색창 아래에 ⭐ 우선참조 목록을 바로 붙인다.** 첫 화면이 빈 검색창만 남지 않고, 무엇이 들었는지 즉시 보인다.
- 검색은 **입력 즉시**(`input` → `requestAnimationFrame` 한 번). 디바운스로 글자를 늦추지 않는다. 0.1초 안에 바뀌면 진행 표시가 필요 없다.
- 검색창은 `grid`/`flex` 안에서 **`minmax(0,1fr)`·`min-width:0`**을 명시한다. 기본 `auto` 트랙은 입력칸의 고유 폭만큼 늘어나 휴대폰에서 화면 밖으로 밀린다(2026-11-17 `/law/` 실측: 390px 화면에서 히어로가 422px).

## 2. 결과 한 줄 — 왜 걸렸는지 함께

- 결과는 카드가 아니라 **한 줄 링크**(이름 · 종류 · 맞은 이유 · 화살표). 한 줄 전체가 44px 이상의 누를 곳이다.
- **맞은 이유를 적는다**: `「소개비」 상담 상황 · 제19조·제32조`. 두 번째 결과를 열어 보는 왕복이 줄어든다.
- 검색어는 이름과 이유 줄에 `<mark>`(형광 띠)로 표시한다.
- 정렬은 `관련도 → 우선참조 → 번호`. 검색어가 없으면 우선참조만 보인다.
- 결과가 0건이면 **문장만 두지 않는다**: 「법전 목차 열기」·「검색 지우기」 두 단추를 함께 둔다.
- 검색어는 **동의어 사전**으로 넓힌다(`알바`·`아르바이트`, `국취`·`국민취업지원제도`). 조문 본문에 없는 말도 사전에 넣어 걸리게 한다.

## 3. 상세 — 세 칸, 없는 칸은 사라진다

- ① 쉬운 풀이·실전 예시 ② 시각자료 ③ 조문 전문. **②가 없으면 칸 자체를 만들지 않는다**(빈 슬롯·빈 상자 0).
- **휴대폰**: 탭 2~3개(풀이·사례 / 시각자료 / 조문). 시각자료가 없으면 탭도 2개. 탭은 `hidden`이 아니라 `display`로 바꾸되 상태는 `aria-selected`에 남긴다.
- **큰 화면(≥900px)**: 왼쪽 = 풀이·사례, 오른쪽 = 시각자료 위·조문 아래(2단). 조문 본문은 `max-height`(30vh 안팎) 상자 안에서 넘긴다 — 쪽 전체가 길어지지 않게.
- 상세의 머리(이름·한 줄·시행·공포·소관·원문 링크·상황 칩)는 **한 덩어리**로 두고 휴대폰·큰 화면이 같은 DOM을 쓴다.
- 조문 칩(제○조)은 44px, 누르면 아래 본문만 바뀐다(쪽 이동 없음). 출처·저작권 한 줄은 상자 바닥에 고정한다.
- 화면 분량: 큰 화면 ≤1.5, 휴대폰 ≤2.5. 큰 화면에서 넘칠 때는 **칸 안 스크롤**보다 **콘텐츠를 줄이는 쪽**을 먼저 본다(긴 예시 문장을 다듬는 것이 상자를 자르는 것보다 낫다, 2026-11-17 `/law/`에서 1.78→1.44).

## 4. 가변형 시각자료 (`visual`)

- 자료에 `visual`이 있으면 **내용 높이만큼** 늘어난다(고정 비율 금지). 종류: `bars` · `compare` · `flow` · `timeline`.
- 색은 화면 토큰(`--acc`·`--ink`·`--muted`)만 쓴다 → 밝게/어둡게가 자동으로 맞는다. 외부 라이브러리·이미지 0.
- 막대는 `width`가 아니라 **`transform:scaleX()`**(정적)로 그린다. 값 라벨은 원자료 단위 그대로.
- `flow`는 좁으면 세로, 440px부터 2열, 760px부터 3열 — 단계 수가 늘어도 높이가 선형으로 늘지 않는다.

## 5. 책처럼 보기 — 위치 감각

- 목차(장 → 절)에서 바로 들어가고, 한 쪽에 한 조문. **쪽 번호 `12 / 50`**과 목차의 현재 절 표시가 위치를 만든다(점 인디케이터 금지).
- 조작: 앞뒤 단추 + `←/→`·PageUp/Down·Home/End + 가로 끌기(48px, 세로 우선) + 휴대폰 목차 시트.
- 쪽 전환은 컨테이너를 갈아엎지 않고 **안쪽 글자만 교체**하고 `transform`·`opacity`로 0.2초. 전환 시작·끝에 `jc-busy`를 보내 형광펜·포스트잇이 새 자리를 다시 잰다.
- 주소에 현재 쪽(`#book=<id>/<조문>`)을 남겨 새로 고침·뒤로 가기가 먹게 한다. 쪽 이동은 `replaceState`(뒤로 가기 한 번에 리더를 닫는다).
- 리더에서는 페이지 바닥 안내(`.foot`)와 「이어 보기」 줄을 숨긴다(`html.book-mode`).

## 6. 검수 (이 유형에서 재는 것)

- [ ] 입력 8타/초에서 결과 갱신 p95 ≤ 50ms
- [ ] 쪽 넘김 프레임 p95 ≤ 33.4ms, 100ms 멈춤 0
- [ ] 시각자료 유/무 두 경우 모두 빈 슬롯 0
- [ ] 390·360·820·1024·1280·1600 밝게/어둡게: 오류 0 · 넘침 0 · 44px 미달 0
- [ ] 상세 화면 분량 큰 화면 ≤1.5 · 휴대폰 ≤2.5 (모든 항목에 대해)
- [ ] `minmax(0,1fr)` 누락으로 히어로가 화면 밖으로 밀리지 않는가(폭 390에서 `body.scrollWidth == innerWidth`)

## 7. 도태 (다시 쓰지 않는 것)

- **고정 높이 3칸 팬(pane)에 긴 글을 넣기** — 문단이 상자 아래에서 잘려 「잘린 화면」으로 보인다. 같은 날 실측에서 1.0화면을 얻었지만 읽는 화면으로는 답답하다. 대신 콘텐츠를 줄이고 자연 흐름 + 조문 상자만 스크롤.
- **검색 히어로를 `align-items:end`로** — 오른쪽 칸이 길면 제목이 아래로 내려가 왼쪽 위가 큰 빈 자리가 된다.
- **결과 줄에 태그를 문장 안에 붙이기** — `법률 ⭐ 소개비·직업소개소…`처럼 읽혀 태그가 문장으로 보인다. 태그 뒤에 7px 간격을 두고 이유 줄을 분리한다.

## 8. 용어 번역기 · 사전형 — 2026-11-19 `/translator/`

낱말 하나가 곧 화면 한 장이고, 내담자가 쓴 **현장 말**을 상담사의 언어로 옮기는 화면. 법전(§1~§5)과 같은 「검색 한 칸 + 한 줄 결과」를 쓰되, 결과가 목록이 아니라 **용어 → 뜻 → 맥락 → 질문 → 연계**의 카드다.

- **검색 칸 하나가 곧 목차.** 자주 듣는 말 칩은 법령 이름이 아니라 **내담자가 실제로 하는 말**(`MES`·`수율`·`국취`)로 만든다.
- **초성 검색은 두 갈래를 모두 받아야 한다.** 한글 음절을 첫소리로 바꾸는 변환(`국취`→`ㄱㅊ`)과, 입력이 이미 초성일 때 그대로 비교하는 길(`ㄱㅊㅈ`). 한쪽만 있으면 초성 입력이 0건이 된다(2026-11-19 실측: 초성 비교가 `isHangul`에 걸려 통째로 건너뛰어 「ㄱㅊㅈ」가 빈 결과였다).
- **두 단(목록|상세)에서 큰 화면은 첫 항목을 미리 펼친다.** 빈 오른쪽에 안내 상자만 두면 화면 절반이 죽는다. 미리 펼친 선택은 **주소에 남기지 않는다**(`hash:false`) — 뒤로 가기가 첫 항목을 닫는 일이 없게.
- **휴대폰은 목록 ↔ 한 장 보기**를 `body` 클래스 하나로 가른다. 한 장에서 뒤로 가기·Esc가 목록 복귀가 되고, 그때 머리·탭·이용 안내를 숨겨 카드가 첫 화면에 바로 온다.
- **쪽 나눔은 8칸.** 10칸이면 390에서 두 화면을 넘고, 8칸이면 목록 1.47~1.59화면·상세 1.08화면이다. 쪽 단추는 44px, 쪽 번호는 `3 / 26` 위치 숫자.
- **분야 탭 5칸은 좁은 화면에서 이름을 줄인다.** 화면 글자는 「직무·산업·학력·제도」, 전체 이름은 `aria-label`로 남기고 좌우 여백 10px를 확보한다(전체 이름을 그대로 두면 390에서 두 줄로 깨지거나 좌우 6px까지 눌린다).
- **연계 칩은 대상 섹터의 주소 규칙을 따른다.** `?q=`를 받는 섹터(taxonomy·company·thermometer·emerging·decalcomania·univ·grad)와 `#list?q=`를 쓰는 섹터(cert), `?q=`가 없는 섹터(첫 화면으로)를 구분한다. **검색어는 그 섹터 자료에 실제로 있는 이름**이어야 한다 — 없으면 빈 결과가 열리므로, 만들 때 데이터와 전수 대조한다.
- **모르는 것은 출처를 비운다.** 기관 정의가 없는 현장 약어는 「공식 정의를 붙이지 않은 말」로 적고, NCS는 정의문이 아니라 **그 말이 속한 직무 영역**의 근거로만 단다.
