운영 중

로그인하지 않아도 자료실의 모든 기능을 제한 없이 사용할 수 있습니다. 로그인은 내가 본 내용과 학습 기록(탐색 진도·형광펜·포스트잇 메모 등)을 저장하고 다른 기기와 동기화하기 위한 선택 기능입니다.

자료실의 정보는 정답이 아닌 참고·실습용 도구입니다. 직업상담 실무 연습과 탐색을 돕기 위한 자료이므로, 실제 판단은 최신 공식 자료와 기관 안내로 확인해 주세요.

  • 아이디와 비밀번호만 받습니다. 이름·이메일·전화번호 같은 개인정보는 받지 않습니다. 로그인하지 않으면 모든 기록은 지금 쓰는 기기의 브라우저에만 남습니다.
  • 비밀번호는 되돌릴 수 없는 방식(bcrypt)으로 암호화해 저장합니다. 운영자도 원래 비밀번호를 볼 수 없습니다. 그래서 비밀번호를 잊으면 찾을 수 없습니다.
  • 메모에 내담자의 이름·연락처·주민등록번호 등 개인정보를 적지 마세요. 이 사이트는 학습과 업무 정리를 돕는 도구입니다.
  • 언제든 로그아웃하고, 계정과 서버의 기록을 완전히 지울 수 있습니다. 로그인 → 내 계정 → 계정과 기록 완전히 삭제.

연동하는 기록
탐색 진도, 형광펜과 포스트잇 메모, 도구함 색 설정, 화면 테마, 이론 위키 학습 기록, 실무 가이드에서 마지막으로 본 단계
연동하지 않는 것
상담 HUD에 입력하는 상담일지와 계산 내용(어디에도 저장되지 않습니다), 환승노선도에 입력한 내 케이스(이 기기에만 저장), 검색어, 내가 본 페이지 목록
이용 통계
사이트를 고쳐 나가기 위해 페이지를 열 때마다 익명 한 줄만 남깁니다: 어느 꼭지인지, 로그인 상태였는지(예/아니오), 기기 종류(휴대폰·태블릿·PC), 이 브라우저에서 오늘 처음인지, 처음 들어온 곳의 도메인 이름(예: google.com), 자료실 안에서 옮겨 왔다면 바로 앞 꼭지, 화면을 보고 있던 시간(5분 넘게 손대지 않으면 멈춤). IP 주소·아이디·쿠키·기기 고유번호·검색어·입력한 내용은 남기지 않으며, 어떤 줄도 특정 사람이나 계정과 이어지지 않습니다. 브라우저의 '추적 안 함'·GPC 설정을 켜 두면 남기지 않습니다. 400일이 지나면 지웁니다.
저장 위치
Supabase 데이터베이스(서울 지역). 오가는 내용은 모두 HTTPS로 암호화됩니다.
접근 범위
각 계정은 자기 기록만 읽고 쓸 수 있도록 데이터베이스에서 막아 두었습니다. 로그인 상태는 무작위 열쇠로 유지되며 180일 뒤 만료됩니다.
운영자가 볼 수 있는 것
사이트 화면에서는 관리자도 가입된 아이디의 개수와 위 이용 통계의 합계만 볼 수 있습니다. 다만 데이터베이스를 관리하는 운영자는 기술적으로 아이디와 저장된 기록(메모 내용 포함)을 볼 수 있는 권한이 있으니, 민감한 내용은 적지 마세요. 비밀번호는 운영자도 볼 수 없습니다.
무단 로그인 방지
같은 아이디로 비밀번호를 10번 틀리면 15분 동안 잠깁니다. 비밀번호는 다른 사이트와 다르게 정해 주세요.

      자료 선반

        모든 자료를 꽂았습니다.

        나만의 목차 꽂는 법시드 · 매치

        이 사이트의 자료는 AI의 도움을 받아 만든 비공식 학습·업무 보조 자료입니다. 고용노동부, 한국고용정보원 등 어떤 기관의 공식 자료도 아닙니다.

        기준 개정·저작권 안내

        제도 기준과 수치는 개정될 수 있습니다. 실제 업무 판단은 반드시 공식 법령·고시·지침 원문으로 확인하십시오.

        인용한 보고서·매뉴얼·검사·공공데이터의 저작권은 각 발행 기관과 저자에게 있습니다. 자료실은 원문을 옮겨 싣지 않고 요약과 짧은 인용만 쓰며, 각 자료 화면에 출처와 이용 조건을 밝힙니다.

        보기 방식

        어느 쪽으로 담을까요

        한 번 눌러 미리 보고, 다시 눌러 그 방식으로 넘어갑니다.

        값을 다루는 방식검증 공개 2026-11-19 기준

        숫자·조문·요건은 기억이나 추측으로 쓰지 않습니다. 값마다 공식 출처와 기준시점을 붙이고, 확인되지 않은 값은 비웁니다. 아래는 그 규칙과, 실제로 자동 검사하는 항목입니다.

        세 가지 규칙

        1. 값마다 출처와 기준시점법령 조문·공시·공공데이터·공식 통계만 싣고, 기관과 기준일을 함께 적습니다. 예: 지방공공기관 1,315곳 — 행정안전부 2026.6.30 현황.
        2. 확인 안 되면 비웁니다원자료에 없는 값은 지어내지 않고 줄을 만들지 않습니다. 빠진 항목은 「미표기 항목」으로 밝히고 시행기관 공식 안내로 잇습니다. 기업 명함첩의 매출·정원, 자격증 도감의 시험 일정이 그렇게 비어 있습니다.
        3. 계산은 공식 산식으로금액·기한은 조문과 산식에 값을 넣어 계산합니다. 계산에 넣은 값과 결과를 화면에 함께 남깁니다 — 예: 국취 상담 HUD의 구직촉진수당 감액.

        자동 검사 — 통과해야 배포됩니다

        • 자료 검사모든 자료 파일의 형식과 서로 가리키는 항목이 맞는지, 저작권 표시가 바르게 달렸는지, 화면에 넣은 계산·판정 규칙이 지면 목록과 어긋나지 않는지 — 고칠 때마다.
        • 실화면 검사대문·브리핑·산업 온도계를 실제 브라우저로 휴대폰 390·데스크톱 1280에서 — 콘솔 오류 0 · 같은 사이트 404 0 · 가로 넘침 0 · 44px 미달 0.
        • 매일 라이브 검사매일 06:30(KST)에 섹터 전 지면이 열리는지, 오늘 지면이 실렸는지 확인합니다.

        이 대문을 올린 변경도 위 검사를 통과한 뒤 배포되었습니다.

        이 검사가 하지 않는 것

        숫자가 사실인지 자동으로 판정하지는 않습니다. 원문 대조는 사람이 합니다. 요약 문장 일부는 AI가 작성했으므로, 숫자·조문은 위 출처에서 다시 확인하실 수 있게 달아 두었습니다. 실제 판단은 최신 공식 원문과 기관 안내로 확인하십시오.
