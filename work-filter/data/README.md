# 직업 현실 리얼 필터 — 자료 안내

내담자가 원하는 근무 조건을 고르면 조건에 맞는 직무가 걸러지는 화면(`/work-filter/`)이 읽는 자료 셋.
화면은 이 파일들을 **읽기만** 한다. 다시 만들려면 아래 `build_*.py`를 돌린다.

| 파일 | 무엇 | 만드는 곳 |
|---|---|---|
| `work-context.json` | 직무(KSCO 제8차 세분류 489개)마다 근무환경 여섯 축 값(0~100)과 「주로 만나는 사람」, 그 근거 | `build_work_context.py` |
| `clusters.json` | 산업 분야 29개·지역 162곳의 기업 수와 지역 분포 | `build_clusters.py` |
| `job-fields.json` | 직무 이름에 산업 분야 낱말이 겹칠 때만 잇는 참고 연결 334건 | `build_clusters.py` |

검사: `python3 work-filter/data/validate.py` (구조·값 범위·집계 일치·출처·라이선스).

## 1. 근무환경 프로필 — `work-context.json`

**원자료만 쓴다. 값은 하나도 지어내지 않는다.**

1. **O*NET® 31.0 Database** — `Work Context.txt`·`Work Activities.txt`·`Occupation Data.txt`.
   미국 노동부 취업훈련청(USDOL/ETA), **CC BY 4.0**(재가공·재배포 허용, 출처 표시).
   https://www.onetcenter.org/database.html (`db_31_0_text.zip`, 2026-08-30 배포)
2. **ISCO-08 ↔ 2010 SOC 연계표** — 미국 노동통계국(BLS), 미국 연방정부 저작물(퍼블릭 도메인).
   https://www.bls.gov/soc/soccrosswalks.htm (`ISCO_SOC_Crosswalk.xls`, 2012-08 / 2015-06 갱신)
3. **2010 SOC ↔ 2018 SOC 연계표** — BLS. https://www.bls.gov/soc/2018/crosswalks.htm (`soc_2010_to_2018_crosswalk.xlsx`)
4. **한국표준직업분류(KSCO) 제8차 ↔ ISCO-08 연계표** — 국가데이터처(구 통계청) 통계분류포털, 2025-11-03 게시.
   https://kssc.mods.go.kr:8443/ → KSCO > 연계표 (공공누리 제1유형)
5. **KECO 2025 ↔ KSCO 8차 연계** — 한국고용정보원 공식 매핑을 자료실 `taxonomy/data/taxonomy.json`에서 그대로 받아 쓴다.
   (화면에 고용24 직무분류 이름을 함께 보여 주기 위해서다.)

연계 사슬은 **공식 표만** 탄다:

```
O*NET-SOC(8자리) → 2018 SOC → 2010 SOC → ISCO-08 세분류(4자리) → KSCO 제8차 세분류(4자리) → KECO 2025 세분류
```

### 여섯 축 (0~100)

| 축 | 뜻 | O*NET 원소(Work Context, 괄호는 업무활동) | 환산 |
|---|---|---|---|
| `field` 현장성 | 사무실 ↔ 현장·야외 | 실내·비통제 / 야외·전천후 / 야외·지붕 아래 | 세 값의 평균을 100점으로 |
| `people` 사람 대면 | 혼자 ↔ 고객·민원 응대 | 타인 접촉 / 외부 고객 응대 / 대면 토의 | 세 값의 평균 |
| `team` 팀 협업 | 혼자 맡은 일 ↔ 팀으로 | 팀 작업 중요도 / 타인 조율·지휘 | 두 값의 평균 |
| `screen` 컴퓨터·이메일 | 몸으로 하는 일 ↔ 컴퓨터 중심 | (Working with Computers) / 이메일 빈도 | 두 값의 평균 |
| `travel` 이동·차량 | 한곳에서 ↔ 차량·이동 | 밀폐 차량·장비 / 개방 차량 / 걷기·뛰기 | 세 값의 평균 |
| `shift` 교대·불규칙 | 정해진 시간 ↔ 교대·불규칙 | 근무 일정(3단: 정규·불규칙·계절) | (값−1)÷2×100 |

O*NET 응답은 1~5(근무 일정만 1~3)라 `(값−1)÷4×100`으로 100점으로 옮긴다.
`cuts`는 그 축에서 직무들을 값 순서로 3등분한 경계다 — 화면의 **「낮은 편·보통·높은 편」**이 이 값이다.

### 정직하게 비워 둔 것

- **값이 없는 축은 `null`**이고 `missing`에 적는다. 근거가 하나라도 없으면 그 축은 비운다. (489개 중 485개가 여섯 축 모두 값이 있다. 4개 — 의회 의원 등 — 는 O*NET 응답 자체가 없다.)
- **팀 인원수·연봉·출장 일수처럼 O*NET에 없는 값은 만들지 않는다.**
- 한 KSCO 칸에 여러 O*NET 직업이 이어지면(연계표가 1:N·N:1) **가중 평균**하고 `onet_n`에 몇 개가 들어갔는지 남긴다. 한 O*NET 직업이 여러 ISCO로 갈리면 그 수만큼 무게를 나눠 갖는다(1÷ISCO 수) — 감독자 직업이 다른 분류에 과하게 섞이는 것을 줄인다. 그래서 값은 「그 직무의 정확한 측정」이 아니라 「그 분류 칸의 평균」이다.

## 1-b. 주로 만나는 사람 — `who`

같은 O*NET 원자료(Work Context · Work Activities)의 항목만으로 **네 갈래 점수**를 만든다. 새 값을 지어내지 않는다.

| 갈래 | O*NET 항목(괄호는 업무활동) |
|---|---|
| 외부 고객·대중 | 외부 고객 응대 · (조직 밖 사람과 의사소통) · (설득·영향) · (대중 직접 상대) · 연설 |
| 돌봄·지도 대상 | (돌봄·부조) · (교육·훈련) · (코칭) |
| 내부 팀·동료 | 팀 작업 · (상사·동료와 의사소통) · 타인 조율·지휘 |
| 민원·갈등 응대 | 불친절·화난 사람 응대 · 폭력적·공격적 사람 응대 · (갈등 해결·협상) |

- 점수는 갈래별 항목의 0~100 환산값 평균.
- **대표 갈래**는 셋(외부 고객·돌봄·내부 팀)만 겨룬다. 갈래마다 그 갈래의 중앙값·p10·p90으로 표준화한 뒤(다른 직무와 견준 상대 위치) 가장 두드러지는 쪽을 고른다.
- 타인 접촉(Contact With Others)이 직무들의 **하위 20%** 이내면 `alone`(대면 적은 단독 집중).
- 어느 갈래도 두드러지지 않고 접촉이 중앙값 미만이면 `alone`, 그 이상이면 `mixed`(여러 대상과 고루).
- 민원·갈등 점수가 상위 3분의 1 이상이면 `conflict: true` — 만나는 대상이 아니라 성격이라 대표 갈래와 따로 표시한다.
- 결과 분포: `alone` 141 · `care` 136 · `internal` 100 · `customers` 97 · `mixed` 15 · 민원·갈등 표시 159.

## 2. 지역·산업 클러스터 — `clusters.json`

자료실 **기업 명함첩**(`company/data/`)의 실제 소재지 주소를 시군구로 묶어 센 값이다.

- 대기업·중견기업·공공기관 **7,822곳**(공정거래위원회 기업집단포털 · 알리오 · 중견기업정보마당 · 국민연금 가입 사업장)
- 지방공공기관 **1,315곳**(행정안전부) → 합계 **9,137곳**
- 이 가운데 업종(KSIC 세세분류 이름)이 있는 **7,017곳**을 산업 분야 29개로 묶고, 주소가 있는 **4,080곳**으로 지역을 셌다.
- **산업 분야는 자료실이 만든 편집 기준**이다(공식 산업통계 분류가 아니다). 어떤 업종 이름이 어느 분야로 갔는지 `fields[].ksic_names`와 `field_keywords`에 그대로 남겼다.
- 주소가 공개되지 않은 기업은 지역 집계에서 빠진다. 분야마다 `with_address`(주소 공개 기업 수)를 함께 싣고, 60% 미만이면 화면에 그 사실을 적는다.
- 지역 단위: 광역시는 **구**(서울특별시 강남구), 도는 **시·군**(경기도 평택시).

## 3. 직무↔분야 참고 연결 — `job-fields.json`

직무 이름에 산업 분야의 낱말이 **실제로 들어 있을 때만** 잇는다(예: 「반도체 장비 기술자」 → 반도체).
공식 직무↔산업 매핑이 아니므로 화면에도 「이름이 겹쳐 이은 참고 연결」이라고 적는다. 겹친 낱말은 `basis`에 남는다.
489개 가운데 334개가 이어진다. 나머지는 화면이 「겹치는 분야 없음」으로 정직하게 비운다.
