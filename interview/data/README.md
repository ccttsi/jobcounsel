# 면접 전술 덱 (TCG 방식 면접 스킬 아레나) — 데이터셋 v1.0.0

> 자료실에서는 이 폴더(`/interview/data/`)에 두고 「면접 전술 덱」(`/interview/`)이 읽습니다.
> 화면을 구현하는 코드는 **`SCHEMA.md`를 먼저 읽습니다.** 이 문서는 데이터의 내용·출처·한계를 설명합니다.

면접을 **카드 배틀의 문법**으로 연습하는 도구의 데이터다. 면접관의 질문이 한 장의 카드로 놓이고,
내 손에는 그 질문에 대는 카드가 3~4장 온다. 어떤 카드는 **쓰면 지는 카드**(함정)이고,
어떤 카드는 **정석**(방어), 어떤 카드는 **한 문장을 남기는 카드**(카운터)다.
직무와 무관한 사생활·차별 질문에는 **법과 직무 기준으로 되돌리는 카드**(실드)가 따로 있다.

- 만든 날: 2026-11-16
- 형식: UTF-8(BOM 없음) JSON 1개 · 약 151KB
- 스키마 계약: [`SCHEMA.md`](SCHEMA.md)
- 검증: `python3 interview/data/validate.py` → **오류 0건, 경고 0건** (2026-11-16)
- 라이선스: 자체 설계 프레임워크(자료실 직접 작성). 법령·공공 안내는 출처 표시, 언론 보도는 사실·수치만 인용.

## 2. 카드 한 장의 생김새

```jsonc
{
  "id": "enc13",
  "arena": "standard",
  "sub_mode": "rights_boundary",
  "interviewer": "인사 담당 · 사생활 질문",
  "question": "결혼은 하셨습니까? 출산 계획은 어떻게 되십니까?",
  "context": "주로 여성 지원자에게 나오는 질문. 장기 근속 가능성을 확인하려는 의도로 나오지만 기준이 직무가 아니다.",
  "answer_goal": "사생활 정보를 주지 않고, 근무 가능성이라는 직무 기준으로 대화를 되돌린다.",
  "pressure_level": 3,
  "time_limit_sec": 60,
  "hidden_intent": "직무와 무관한 혼인·출산 계획을 확인하려는 질문이다. …",
  "legal_flag": "violation_alert",
  "legal_basis": "채용절차의 공정화에 관한 법률 제4조의3은 … 500만원 이하의 과태료를 부과한다(제17조 제2항 제3호). …",
  "legal_note": "답하지 않아도 불이익을 줄 수 없다. …",
  "hand_cards": [
    { "card_type": "trap",    "title": "성실하게 답하기",  "script_formula": "…", "why_effect": "…", "pace_split": {"intro": 0, "case": 0, "link": 0, "note": "이 카드는 쓰지 않는다"} },
    { "card_type": "shield",  "title": "완충 → 전환 → 대안", "script_formula": "…", "why_effect": "…", "pace_split": {"intro": 10, "case": 35, "link": 15, "note": "완충 10초 · 전환 35초 · 대안 15초"} },
    { "card_type": "defense", "title": "직무 기준 재확인", "script_formula": "…", "why_effect": "…", "pace_split": {"intro": 10, "case": 35, "link": 15, "note": "…"} },
    { "card_type": "counter", "title": "질문의 목적 되묻기", "script_formula": "…", "why_effect": "…", "pace_split": {"intro": 10, "case": 20, "link": 0, "note": "질문 1개 · 20~30초"} }
  ],
  "coach_note": "화를 내거나 법을 들이미는 것이 목적이 아니다. …"
}
```

- `[ ]` 자리는 **사용자의 사실로 채우는 자리**다. 화면은 이 자리를 입력칸이나 강조로 남긴다.
- `pace_split`은 **턴 타이머의 재료**다. `defense`·`shield`는 합이 `time_limit_sec`과 정확히 같다.
- `trap` 카드는 "쓰지 않는 카드"다. 시간 배분이 0이고, `why_effect`에 탈락 이유가 있다.

## 4. 이 데이터가 하지 않는 것

1. **합격을 보장하지 않는다.** 카드의 문장은 자료실이 직접 쓴 **예시**다.
2. **법률 자문이 아니다.** 법조문과 인권위 결정을 요약했을 뿐, 개별 사안의 판단은 노무사·변호사·인권위 상담을 따른다.
3. **회사를 평가하지 않는다.** `legal_flag`는 질문의 성질이지 그 회사의 성격이 아니다.
4. **공고를 대신하지 않는다.** 전형 이름·시간·배점은 지원하는 회사·기관의 공고 원문이 우선이다. `trends_2026`은 흐름이다.
5. **보도 수치를 확정값으로 쓰지 않는다.** `confidence`가 `reported`·`single_source`인 항목은 "보도에서 확인된 값"으로 표시한다.
6. **없는 수치를 만들지 않는다.** 카드의 `[숫자]`·`[기간]`은 사용자가 자기 사실로 채운다.

### 데이터 한계

- 질문 38장은 **대표 유형**이지 실제 면접 질문의 전수가 아니다. 직무·산업별 질문은 21-1 후보로 남겨 두었다.
- AI 전형의 운영 방식은 기업마다 빠르게 바뀐다. 2026년 하반기 보도 기준이며, 2027년 공고에서는 달라질 수 있다.
- 면접의 구두 질문은 채용절차법 제4조의3의 직접 제재 대상이 아니다(고용노동부 FAQ). 이 데이터는 그 경계를 `legal_basis`·`legal_note`에 나눠 적었다.
- 인권위 결정 사례는 개별 사안의 판단이다. 같은 질문이라도 맥락에 따라 결론이 달라질 수 있다.

## 5. 다시 만들고 검증하려면

이 데이터는 공공 통계가 아니라 **자료실이 직접 쓴 프레임워크 데이터**다. 원자료를 다시 내려받는 스크립트는 없고, 내용을 고칠 때는 JSON을 직접 수정한 뒤 검증기를 돌린다.

```bash
python3 interview/data/validate.py            # 구조 검증 (오류 0건이어야 배포)
python3 interview/data/validate.py --selftest # 카드 조립 참조 구현까지 실행
```

검증기가 막는 것: 시간 합이 제한 시간과 다른 카드, 카드 종류가 빠진 핸드, 근거 없는 법적 신호, 없는 출처 id, `meta.counts`와 실측의 불일치, 카드 본문에 섞인 HTML·외부 주소·내보내기 문구.

## 6. 저작권·디자인 원칙

- **특정 TCG 게임이나 타 사이트의 UI·그래픽 자산을 복제하지 않는다**(`DESIGN.md` §0). 게임에서 가져오는 것은 **일반 원리**(정보 위계, 턴의 리듬, 시간 압박의 감각)뿐이다.
- 턴 타이머는 자료실 고유 설계다. 특정 게임의 밧줄·폭탄·스킨·레이아웃을 모방하지 않고, `🎨 디자인 학습함`의 수집 자료와 `DESIGN.md` 진화형 창조 루프로 독자 장치를 만든다.
- 문장은 전부 자료실이 쓴 것이다. 합격 자소서·기업 인재상 문구·검사 문항을 옮기지 않았다.
- 화면에 저장·인쇄·PDF·복사 버튼을 두지 않는다.
