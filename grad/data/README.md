## 3. `grad_departments.json` 구조

```jsonc
{
  "meta":      { "counts": {...}, "limitations": [...] },   // 건수·한계 요약
  "sources":   [ ... ],                                      // 출처 3종
  "columns":   ["gs","name","so","years","degree","time","track","state","code","college","spot","dist"],
  "column_notes": { ... },                                   // 컬럼 설명
  "degree_flags": { "1": "석사", "2": "박사", "4": "석박사통합", "8": "학석사통합" },
  "grad_types": ["일반대학원","전문대학원","특수대학원"],
  "unis":         [ ... 251곳 ... ],
  "grad_schools": [ ... 1,169곳 ... ],
  "departments":  [ ... 12,731행 ... ]                       // 컬럼 배열(순서 고정)
}
```

### `unis[]` — 대학 1곳

```jsonc
{ "id":"U113", "name":"서울대학교", "base":"서울대학교", "region":"서울",
  "found":"국립", "kind":"대학", "grad_schools":12, "depts":186 }
```

| 필드 | 뜻 |
|---|---|
| `name` | 대학알리미 학교명. 캠퍼스가 따로 공시되면 `영산대학교(양산)`처럼 괄호가 붙은 채로 둠 |
| `base` | 괄호를 뗀 모교명(`영산대학교`) — 캠퍼스 합산용 |
| `found` | 국립 / 공립 / 사립 / 기타 (2023 공시 기준, 아래 한계 3 참고) |
| `kind` | `대학` / `대학원대학` / `단독대학원` |
| `grad_schools`,`depts` | 이 대학의 대학원 수·학과 수 |

### `grad_schools[]` — 대학원 1곳

```jsonc
{ "id":"G0529", "name":"대학원", "uni":112, "type":"일반대학원", "kind":"대학",
  "campus":"", "region":"서울", "found":"국립", "code":"0000790",
  "depts":149, "degrees":["석사","박사","석박사통합"], "closed_depts":12,
  "display":"서울대학교 대학원" }
```

| 필드 | 뜻 |
|---|---|
| `id` | `G0001`~ (이 파일 내부 식별자) |
| `uni` | `unis` 배열 인덱스 |
| `name` | 대학원명(`대학원`, `교육대학원`, `법학전문대학원` …) |
| `type` | **일반대학원 / 전문대학원 / 특수대학원** — 원자료 `학교구분` 값 그대로 |
| `code` | 대학원별 대학알리미 학교코드 |
| `degrees` | 이 대학원 개설 학과에 있는 학위과정(중복 제거) |
| `closed_depts` | 같은 대학원에서 **폐지로 빠진 학과 수**(이 파일에는 미포함) |
| `display` | 화면 표시용 이름(대학원대학은 중복 없이 학교명만) |

### `departments[]` — 학과 1건 (12칸 고정)

| 칸 | 필드 | 설명 | 예 |
|---|---|---|---|
| 0 | `gs` | `grad_schools` 인덱스 | `528` |
| 1 | `name` | 학과·전공명(원문) | `간호학과` |
| 2 | `so` | 소계열 코드(`grad_taxonomy.json`의 `so[].code`) | `S062` |
| 3 | `years` | 수업연한(년) | `4.0` |
| 4 | `degree` | 학위과정 비트합 — 1 석사 · 2 박사 · 4 석박사통합 · 8 학석사통합 | `7` = 석사+박사+통합 |
| 5 | `time` | 주야간(주간/야간/계절제/원격) | `주간` |
| 6 | `track` | 학과특성(일반과정/계약학과/산업체위탁/학석사통합과정) | `일반과정` |
| 7 | `state` | 학과상태(기존/신설/변경[신설]/분리[신설]/통합[신설]) | `기존` |
| 8 | `code` | 대학알리미 학교별 학과코드 | `0053362` |
| 9 | `college` | 단과대학명 (원자료가 `단과대구분없음`이면 빈 문자열) | `""` |
| 10 | `spot` | (학과)소재지 시·도 | `서울` |
| 11 | `dist` | (학과)소재지 시·군·구 | `종로구` |

행은 `(대학원 인덱스, 학과명, 주야간)` 순으로 정렬돼 있습니다.

> **소재지는 학과 단위로 넣었습니다.** 대학원 소재지와 학과 소재지가 다른 행이 429건(예: 경희대 서울·용인, UST의 전국 캠퍼스)이라 시·도 필터가 어긋나지 않게 하려는 것입니다.

## 4. `grad_taxonomy.json` 구조 — 위키 ↔ 대학원 목록 스와핑 키

```jsonc
{
  "meta": { "levels": {"dae":5,"jung":35,"so":192}, "how_to_use":[...], "notes":[...] },
  "dae":  [ {"code":"A1","name":"인문사회계열"}, ... ],
  "jung": [ {"code":"M02","name":"경영・경제","dae":"A1"}, ... ],
  "so":   [ ... 192개 ... ],
  "lookup": { "경영학":"S005", "경영학과":"S005", "상담심리학과":"S032", ... }
}
```

### `so[]` — 대표 전공 = 표준분류 소계열 1개

```jsonc
{ "code":"S005", "name":"경영학", "jung":"M02", "dae":"A1",
  "path":"인문사회계열 > 경영・경제 > 경영학",
  "grad": { "dept":695, "schools":326, "unis":151, "석사":660, "박사":255, "통합":117 },
  "ug_dept": 539,                                  // 학부(학사) 개설 수 — 규모 비교용
  "time": { "주간":345, "야간":337, "원격":13 },
  "contract": 46,                                  // 계약학과 수
  "top_names": [ {"name":"경영학과","n":178}, {"name":"글로벌경영학과","n":25}, ... ],
  "career_majors": [ {"id":"D-23","name":"경영학과","src":"dept","n":393}, ... ],
  "top_schools": [ {"id":"G0132","name":"경희대학교 경영대학원","type":"특수대학원","n":16}, ... ]
}
```

- `grad`의 `dept`는 **대학원 개설 학과 수**, `schools`는 그 학과가 있는 대학원 수, `unis`는 대학 수입니다.
- `top_names`는 그 소계열로 분류된 실제 학과명 상위 6개 — 화면에서 "이 전공이 대학원에서 어떤 이름으로 불리는지" 보여줄 때 씁니다.
- `career_majors`는 커리어넷 표준학과(`D-…`) 중 이 소계열로 분류된 것. 기존 학부 데이터셋(`career-decalcomania/majors.json`)과 **같은 D-번호**를 쓰므로 학부 위키와 대학원 목록을 같은 키로 잇습니다. `src`가 `name`이면 명칭이 같아 연결한 것, `dept`면 개설 분포(60% 이상)로 연결한 것입니다.
- `top_schools`는 그 전공을 가장 많이 개설한 대학원 5곳입니다.

### 스와핑 방법

```
[전공 위키 뷰]  so.code  ──────────────►  [대학원 목록 뷰]
   S005(경영학)                            departments[][2] == "S005" 인 행 = 695개
                                           → grad_schools[행[0]] → unis[대학원.uni]
```

반대 방향은 `departments[i][2]`로 소계열을 얻고 `so[]`에서 그 전공의 위키 항목을 찾으면 됩니다.
`lookup`은 사용자가 "상담심리학과" 같은 학과명으로 검색할 때 소계열 코드를 바로 얻는 사전입니다.

## 5. 바로 쓰는 예

**Python**

```python
import json
G = json.load(open("grad_departments.json", encoding="utf-8"))
T = json.load(open("grad_taxonomy.json", encoding="utf-8"))

cols  = G["columns"]
unis  = G["unis"]
gs    = G["grad_schools"]
depts = [dict(zip(cols, r)) for r in G["departments"]]

# 1) '경영학' 전공의 박사과정 개설 대학원
code = T["lookup"]["경영학"]                       # 'S005'
rows = [d for d in depts if d["so"] == code and d["degree"] & 2]
for d in rows[:10]:
    s = gs[d["gs"]]
    print(unis[s["uni"]]["name"], s["name"], s["type"], d["name"], d["time"], d["spot"])

# 2) 특정 대학원의 개설 학과 (서울대학교 일반대학원)
for i, s in enumerate(gs):
    if s["display"] == "서울대학교 대학원":
        for d in depts:
            if d["gs"] == i:
                print(d["name"], d["years"], d["degree"], d["so"])
        break

# 3) 야간·계절제로 다닐 수 있는 교육학 석사 (재직자용)
edu = T["lookup"]["교육학"]
rework = [d for d in depts if d["so"] == edu and d["time"] in ("야간", "계절제", "원격")]
print(len(rework), "건")

# 4) 대학별 대학원 구성
u = next(u for u in unis if u["name"] == "전북대학교")
for s in gs:
    if s["uni"] == unis.index(u):
        print(s["display"], s["type"], s["depts"], s["degrees"])
```

**JavaScript (GitHub Pages)**

```js
const G = await fetch("/grad-wiki/grad_departments.json").then(r => r.json());
const T = await fetch("/grad-wiki/grad_taxonomy.json").then(r => r.json());

const pick = (majorName, {doctor = false, night = false} = {}) => {
  const code = T.lookup[majorName];
  return G.departments
    .filter(d => d[2] === code && (!doctor || d[4] & 2) && (!night || ["야간","계절제","원격"].includes(d[5])))
    .map(d => {
      const s = G.grad_schools[d[0]];
      return { school: s.display, type: s.type, dept: d[1], years: d[3],
               degrees: d[4], time: d[5], region: d[10] };
    });
};
console.table(pick("경영학", {doctor: true, night: true}));
```

## 6. 데이터 한계 (상담에 쓸 때 꼭 알아둘 것)

1. **학과 목록은 통계목적 자료입니다.** 대학알리미는 "실제 대학에서 모집·운영하고 있는 학과명과 다를 수 있다"고 명시합니다. **지원 전 해당 대학원 모집요강을 확인해야 합니다.** 이 데이터셋은 "무엇이 개설되어 있는지"의 지도이지 모집 공고가 아닙니다.
2. **기준일이 2024-10-07입니다.** 그 뒤의 신설·통합·폐과는 반영되지 않았습니다. (2025년 공시 파일이 나오면 `work-grad/build_grad.py`를 다시 돌려 갱신할 수 있습니다.)
3. **설립구분은 2023년 공시 기준입니다.** 2024년 표기(`국립강릉원주대학교`)와 2023년 표기(`강릉원주대학교`)를 이름 보정으로 이어 붙였고, 2023년 자료에 없던 `국제언어대학원대학교`·`신경주대학교` 2곳은 빈 값입니다.
4. **학위과정은 "개설된 과정"이지 "모집 중인 과정"이 아닙니다.** 원자료는 `석사,박사, 석박사통합`처럼 묶어 표기합니다. 어느 과정이 실제 모집 중인지는 원자료에 없어, 수업연한·학과상태로 추정만 가능합니다.
5. **폐지 학과 7,131건은 넣지 않았습니다.** 대학원별 폐지 건수만 `closed_depts`로 남겼습니다. "예전엔 있었는데 지금은 없는 학과"를 보려면 원자료가 필요합니다.
6. **`N.C.E.`는 미분류입니다.** 학과명이 표준분류에 딱 맞지 않으면 원자료가 `N.C.E.`(Not Classified Elsewhere)로 둡니다. 예: `AI융합교육학과`는 `공학계열 > 교육 > N.C.E.`. 그래서 `N.C.E.` 소계열 노드가 34개(대계열·중계열별) 있습니다.
7. **분류 코드(A·M·S)는 이 데이터셋이 붙인 내부 식별자입니다.** 교육부 공식 코드가 아닙니다. 원자료에는 분류 코드 없이 명칭만 있습니다.
8. **`career_majors` 연결은 100%가 아닙니다.** 커리어넷 학과명이 표준분류 소계열명과 같거나(명칭 일치), 그 학과 개설 레코드의 60% 이상이 한 소계열에 몰릴 때만 이었습니다.
9. **대학원대학 44곳은 `type`이 전문대학원/일반대학원으로 표기됩니다.** 원자료가 그렇게 분류하기 때문이며, `kind:"대학원대학"`으로 구분할 수 있습니다. `칼빈신학대학원` 1곳은 대학명 없이 대학원명만 공시돼 `kind:"단독대학원"`으로 두었습니다.
10. **건수는 캠퍼스 단위입니다.** `영산대학교(양산)`·`영산대학교(해운대)`처럼 캠퍼스가 따로 공시되면 별도 대학으로 셉니다. 모교 단위로 보려면 `unis[].base`로 묶으세요(245곳).

## 7. 다시 만들려면

원자료와 스크립트는 작업공간에 있습니다.

```
work-cd/raw/dep.xlsx        대학알리미 2024 공시 XLSX (55,228행, 자료기준일 2024.10.07)
work-grad/raw/dep2023.csv   대학알리미 2023 CSV (설립구분 보강용, 52,214행)
downloads/career-decalcomania/majors.json   기존 학부 데이터셋(D-… 연결용)

python3 work-grad/build_grad.py   # 두 JSON 생성
python3 work-grad/verify.py       # 참조 무결성·합계·분포 검증
```

`build_grad.py`가 하는 일:
1. XLSX에서 `대학구분`이 `대학원`·`대학원대학`인 행 19,862건을 뽑고 `학과상태`에 '폐지'가 있는 행 7,131건을 뺀다.
2. `학교명`(`가야대학교 보건대학원(김해)` 형태)을 학부 학교명 목록과 맞춰 **대학 / 대학원 / 캠퍼스**로 나눈다 — 1,168곳이 대학에 연결됐고, `칼빈신학대학원` 1곳만 단독으로 두었다.
3. 표준분류 (대계열·중계열·소계열) 조합에 코드를 붙이고, `N.C.E`·`N.C.E.` 표기를 통일한다.
4. `학위과정` 문자열을 비트로, `수업연한`을 실수로 바꾼다.
5. 2023 CSV에서 설립구분을 붙이고, 커리어넷 학과를 소계열에 연결한다.
6. 소계열별·대학원별·대학별 집계를 계산해 붙인다.
