> 이 저장소에서는 `cert/data/`에 두고 `/cert/`(자격증 도감) 화면이 읽습니다. 아래 본문의 `downloads/…` 경로와 `work/certwiki/…` 스크립트는 만든 쪽 작업 공간 기준이며, 관련 직업 연결은 `decalcomania/data/jobs.json`의 직업 id(`J-…`)를 씁니다.

> **띄어쓰기·오탈자 보정(2026-11-16, 자료실)**: 원자료 3038404의 「개요·수행직무·진로 및 전망」 문장에 줄바꿈 자리로 보이는 띄어쓰기 끊김(예: `시스템화 되 어 있어`, `도 시가스`, `건 설하고`)이 많아, 서술 필드(`summary`·`duties`·`outlook`·`acquisition_raw`·`pass_criteria`) 702곳(366건)을 말뭉치 빈도 규칙 + 손 검토로 붙여 고쳤습니다. 분명한 오자 몇 개(수습규모→수급규모, 요규되어→요구되어, 건설기게→건설기계, 센타→센터 등)도 바로잡았습니다. 종목명·과목·시험방식·시행처·일정 값은 바꾸지 않았습니다. 자동 보정이라 덜 고친 곳이 남아 있을 수 있습니다.

직업상담 자료실 `ccttsi/jobcounsel`의 신규 **「자격증 위키」** 섹터가 화면을 그릴 때 쓰는 데이터입니다.
**공공데이터포털(data.go.kr)에서 인증키 없이 내려받을 수 있는 파일데이터**를 직접 받아 정제했고,

확인하지 못한 값은 지어내지 않고 `null`로 두었습니다.

## 2. JSON 구조

```
{
  "metadata":   { version, generated_at, enriched_at, categories_definition, license_note,
                  sources, enrichment_sources, schedule_basis, limitations, counts },
  "categories": [ { key, definition, count, id_prefix } × 4 ],
  "items":      [ { …자격증 객체… } × 830 ]
}
```

### items 필드

| 필드 | 타입 | 설명 |
|---|---|---|
| `id` | string | 분류 접두어 + 4자리 일련번호 (`KT-`기술 · `KP-`전문 · `KN-`민간 · `KA-`능력검정) |
| `category` | string | 4대 분류 중 하나 |
| `grade_or_field` | string \| null | 등급·계열·분야 (기술자격은 `기술사/기능장/기사/산업기사/기능사`, 전문자격은 등급·면허종류, 민간자격은 공인 등급) |
| `name` | string | 종목명 |
| `agency` | string | 시행기관(전문자격은 시행기관, 민간자격은 자격관리자) |
| `ministry` | string \| null | 소관부처 |
| `related_law` | string \| null | 근거 법령(전문자격만) |
| `schedule_pattern` | object | `{ frequency: "연 3회" \| null, typical_months: ["1~3월(필기)", …], note: "…" }` — 특정 연도 날짜가 아닌 **최근 공식 일정의 러프한 패턴** |
| `subjects` | list \| object \| null | 단계가 있으면 `{"필기": [...], "실기": [...]}`, 등급이 있으면 `{"1급": [...], "3급": [...]}`, 단일이면 문자열 배열 |
| `exam_method` | string \| object \| null | 시험방식(문항 수·시간·객관식/필답형/작업형/면접 등). 단계가 있으면 단계별 객체 |
| `pass_criteria` | string \| null | 합격기준 원문 요지 |
| `summary` / `duties` / `outlook` | string \| null | 개요 / 수행직무 / 진로 및 전망 (기술자격·능력검정) |
| `related_jobs` | list | `[{job_id, name, group}]` — `downloads/career-decalcomania/jobs.json` 직업명과의 키워드 매칭 결과(참고용) |
| `official_url` / `official_urls` | string \| null / list \| null | 시행기관·안내 공식 주소(여러 개면 첫 번째를 `official_url`에) |
| `accreditation` | object \| null | 민간자격 공인 유효기간(`valid_from`·`valid_to`·`previous_periods`) |
| `detail_available` | bool | 원자료에 상세(과목·직무 등)가 있는지 |
| `acquisition_raw` | string \| null | 과목 파싱이 안 된 경우 원문 취득방법 요약(정보 보존) |
| `note` | string \| null | 보충 설명 |
| `source` | object | 이 항목의 출처 데이터셋·라이선스 표기 |

- `certs` 값이 문자열이면 `roundSets`의 회차 묶음을 가리키고, 객체면 상태입니다
  (`not_run` 2027년 미시행 · `abolished` 폐지 · `always` 상시검정 · `absent` 계획에서 확인 안 됨).
  `set`+`noWritten`이면 필기 없이 실기만 보는 종목입니다(건축도장·방수·미장·조적 등 17종목).
- **확인하지 못한 값은 넣지 않았습니다.** 그래서 513종목 가운데 468종목만 회차가 붙었고,
  24종목은 `absent`입니다(폐지·통합·이름 변경으로 보이나 근거가 없어 단정하지 않음).
  한국데이터산업진흥원의 최종합격자 발표일 두 개는 원문이 `’26.7.16`·`’26.12.17`로 적혀 있어 비웠습니다.
