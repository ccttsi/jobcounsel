# 직업상담 통합 자료실

직업상담 이론, 심리검사 해석, 직무분석, 국민취업지원제도 실무, 미래고용 보고서, 학과·직업 연결 지도를 익히기 위한 학습·업무 보조 자료 사이트입니다.

사이트 주소: https://ccttsi.github.io/jobcounsel/

### 대문 빠른 검색

대문 위쪽 「빠른 검색」(`Cmd/Ctrl+K`, `/`)은 섹터 이름만이 아니라 그 안의 자료까지 **비서와 같은 엔진**으로 찾습니다
(`assistant/search.js`. 2026-11-19 이전에는 `assets/tools.js`의 섹터 이름만 훑어서 `해커스`를 쳐도 아무것도 나오지 않았습니다).

- **기업·기관 9,137곳** — 이름·브랜드 별칭·업종·대표 제품으로 찾습니다: `해커스` → (주)챔프스터디, `삼전` → 삼성전자(주),
  `파바` → (주)파리크라상, `건보` → 국민건강보험공단, `ㅎㅋㅅ` → 해커스(초성).
- **그 밖의 하위 항목** — 자격증 831 · 용어 625 · 직업분류 6,713 · 이론 163 · 포털 76 · 법령·조문 · 브리핑 · 파슨스 이북 장.
  초성(`ㅂㄷㅊ`)·약어(`경단`·`국취`·`내배`)·조사·띄어쓰기가 어긋난 입력도 같은 규칙으로 풀립니다.
- **왜 떴는지 함께 보여 줍니다** — `별칭 “해커스”`, `이름 앞부분 “국민취업”`, `찾기 낱말 “자격증”`처럼 매칭 근거를 한 줄로 적고,
  어느 섹터의 자료인지(기업 명함첩·직업분류·자격증 도감…)와 짧은 설명을 붙입니다.
- **누르면 그 항목이 열린 상태로 갑니다** — 기업은 그 법인 카드(`company/#MID-…`)로 바로, 나머지는 섹터의 `?q=`·앵커(`cert/#…`, `law/#law=…`)로.
  기업 결과가 많으면 목록 끝에 「기업 명함첩에서 더 찾기」(`company/#list?q=…`)를 붙입니다.
- **첫 화면은 그대로 가볍습니다** — 팔레트를 **열 때** 색인(`index.json`·`index-dirs.json`·`rag-preface.json`)을,
  **첫 글자를 칠 때** 기업 색인(`index-companies.json`, 한 줄에 한 곳)을 받아 브라우저 캐시에 둡니다.
  대문 첫 그리기에서는 어느 것도 받지 않습니다(비서 위젯도 같은 지연 로드를 씁니다).
- 회귀는 `assistant/test/search-cases.json`(`해커스`·`삼전`·`파바`·`건보`·`ㅎㅋㅅ`)와
  `ops/scripts/assistant_search_test.py`의 「대문 빠른 검색 팔레트」 검사가 맡습니다(치기 → 결과 → 클릭 → 그 법인 카드 확인).

### 자료실 비서

오른쪽 아래 도구함 옆의 **「자료실 비서」** 단추로 열립니다(모든 지면에 같은 위젯).

- **찾기 — 키가 없어도 늘 켜져 있습니다.** `assistant/data/index.json`(섹터·자격증·법령·이론)과 `index-dirs.json`(직업분류)·
  `index-companies.json`(기업·기관 9,137곳, 첫 검색 때만 받음)으로
  불완전한 입력에서도 상관성 높은 순으로 자료를 찾아 줍니다. 초성(`ㅂㄷㅊ` → 반도체), 구어체·동의어(`짤림` → 해고·근로기준법),
  **현장 약어·쓰다 만 줄임말**(`경단`·`경단녀` → 경력단절여성, `국취` → 국민취업지원제도, `내배` → 국민내일배움카드,
  `실급` → 구직급여, `고보` → 고용보험), 조사·어순이 어긋난 문장, 조사·어미 제거를 처리합니다(`assistant/search.js`).
  검색창 아래 「이렇게 읽었어요」 칩으로 어떻게 펼쳤는지 보이고, 「먼저 볼 곳」에 선참조 지도가 집은 섹터 2곳을 먼저 보여 줍니다.
- **선참조 지도 — `assistant/data/rag-preface.json`(약 30KB).** 비서가 맨 먼저 받는 작은 지도로,
  색인(540KB)을 뒤지기 전에 섹터를 좁히고 약어를 펼칩니다. 섹터·낱말·약어 사전은 `assets/tools.js`·`assistant/aliases.json`
  에서 매번 다시 만들어집니다(`assistant/build_index.py`). 대화에서는 이 지도가 Gemini 지침에도 함께 가서,
  답을 쓰기 전에 후보 섹터부터 확인하게 합니다.
- **대화 — 로그인 + 내 Google Gemini 키.** 찾은 자료와 「지금 열려 있는 자료」를 근거로 친절한 상담사 말투로 설명합니다.
  실무 모드 4종(쉬운 3줄 · 모의면접·서류 · 교차 비교 · 오프닝 질문), 웹 교차 확인(`google_search` 그라운딩)이 있습니다.
- **기다리는 동안 무엇을 하는지 보입니다.** `묻기`를 누르면 답변 카드 자리에 네 단계 진행 막대가 뜹니다 —
  `검색`(자료실 색인·선참조 지도) → `정리`(근거를 모아 요청 보내기) → `추론`(모델이 답을 만드는 중, 서버가 SSE `stage` 이벤트로 알림) →
  `작성`(글자가 흐르는 중). 지난 단계는 ✓ 로 남고, 기다린 초가 함께 오르며, 답이 끝나면 막대는 사라집니다.
- **내 대화 기록함 — 본인만 봅니다.** 로그인하면 대화가 내 계정의 기록함(`jc_assistant_threads`·`jc_assistant_messages`)에
  쌓여, 비서 창 위 「지난 대화」에서 목록으로 다시 열고 `+ 새 대화`로 새로 시작하며 제목을 바꾸거나 개별·전체 삭제할 수 있습니다.
  두 표는 RLS 를 켜고 anon·authenticated 권한을 회수해 사이트 코드로는 한 줄도 읽을 수 없고, Service Role 을 쓰는
  `assistant-proxy` 만 세션 토큰으로 확인한 `user_id` 로 접근합니다(남의 대화방에는 쓸 수도 없습니다).
  로그아웃 상태에서는 예전처럼 이 브라우저(localStorage)에만 남고, 로그인한 뒤 「이 브라우저에만 있던 대화」를
  계정으로 옮길지는 **한 번 물어본 뒤** 옮깁니다(저절로 올리지 않습니다).
- **내 키 — Google Gemini 하나.** 무료 키 발급 4단계를 자체 제작 도해(SVG)와 `<`·`>` 넘김으로 안내합니다.
- 메시지별 수정·다시·삭제와 「이 대화 지우기」도 그대로 됩니다. 키는 서버에서 AES-256-GCM 으로 암호화하고 끝 4자리만 보입니다.
- 색인 다시 만들기: `python3 assistant/build_index.py` (배포·환경변수는 `supabase/functions/assistant-proxy/README.md`).

### 집중 보기와 공통 디자인 (`assets/prefs.js`)

모든 페이지는 머리말의 `<span data-jc-prefs></span>`와 `</body>` 앞의 `prefs.js`만으로 아래 기능을 물려받습니다. 새 꼭지도 본문을 `<main>`에 담고 이 두 줄을 넣으면 됩니다.

- **집중 보기**: 버튼을 누르면 본문(`[data-jc-content]` → `main` → `[role=main]` → `#main` → `#app`)과 그 조상만 남기고 머리말·메뉴·옆 목록·바닥글을 숨겨 본문을 화면 가득(100dvh) 띄웁니다. 되는 기기에서는 Fullscreen API를 함께 켭니다. Esc나 떠 있는 도구함으로 끝냅니다.
- **떠 있는 도구함**: 집중 보기 중 오른쪽 아래에 연하게 떠 있다가, 마우스가 가까이 가거나 손으로 누르면 또렷해집니다(집중 보기 끝내기·테마·글자 크기). 바깥을 누르거나 3.6초 동안 조작이 없으면 다시 연해집니다. 형광펜 도구함 버튼도 함께 연해집니다.
- **페이지별 조정**: `window.JC_IMMERSIVE = { content, hide, keep, fullscreen }`. 화면을 다시 그리는 요소는 페이지 CSS에서 `html[data-jc-imm] .toc{display:none}`처럼 숨깁니다(예: `/labor/`, `/library/`). 버튼 하나만 둘 때는 `<span data-jc-prefs="immersive"></span>`(서재 읽기 책상).
- **공통 디자인 층**: 종이 결 바탕, 읽은 만큼 차는 색띠(형광펜 다섯 색), 제목 줄바꿈 고르기, 세피아 종이 색, 집중 보기의 교정지 재단선. 모두 `@layer` 안에 있어 페이지 자체 스타일이 이깁니다. 움직임은 `transform`·`opacity`만 쓰고 `prefers-reduced-motion`과 집중 보기에서는 멈춥니다. 끄려면 `window.JC_DESIGN = { grain: false, progress: false }`.
- **손맛 층**(2026-11-15 보강): 위쪽 눈금·색띠(스크롤을 rAF로 묶어 `scaleX`만 바꿔 아이폰 사파리에서도 동작), 제목 옆 소인, 눌리는 카드(`.jc-pop` — 본문 안의 큼직한 링크·버튼을 실행 중에 찾아 오프셋 그림자와 들림·눌림을 단다), 새로 들어온 덩어리의 등장 모션(`.jc-in`). 집중 보기에서는 모두 빠집니다. 주기적으로 다시 그리는 곳에는 `data-jc-still`을 답니다. (2026-11-17: 머리말 아래 어긋난 2톤 인쇄선은 태화님 지시로 걷어냈습니다 — 아래 노란 줄이 남지 않도록 `prefs.js`에서 `.jc-rule`을 지웠습니다.)
- **머리말 접기·펼치기**(2026-11-17, `assets/headfold.css`·`assets/headfold.js`): 머리말에 `data-jc-headfold="이름"`을 달면 머리말 안에 「⌃ 접기」 단추가 붙고, 접으면 44px 손잡이 줄(이름 + 「⌄ 머리말 펼치기」)만 남아 그만큼 본문이 올라옵니다. 상태는 `localStorage 'jc-hf'`에 남고 첫 그림 전에 `<head>` 인라인 한 줄로 적용합니다. 44×44 터치, `height`·`opacity`만 움직이고 `prefers-reduced-motion`이면 즉시. 지금은 대문(`index.html`)만 켜 두었습니다.
- **떠 있는 것은 본문을 가리지 않게**: 집중 보기 도구는 맨 아래 줄의 작은 손잡이 하나로 쉬다가 누를 때만 옆으로 펼쳐집니다. 형광펜 버튼은 손가락으로 쓰는 화면에서 쉬는 동안 오른쪽 가장자리로 반쯤 물러납니다.
- **접어 두기(공용)**: `window.JC_FOLD = [{ box, head | title, on, open } | { head }]`. 휴대폰(900px 미만)에서 상세를 접어 두고 제목을 누르면 펼칩니다. DOM 구조는 바꾸지 않고 클래스·속성만 답니다(상담 대화 연습장, 노동시장 산책에서 사용). DACUM은 모듈을 한 번에 하나씩 보이고, 실무 가이드 항목 카드는 `<details>`로 접습니다.
  펼칠 때는 상자 높이를 보간하지 않고 즉시 연 뒤, 안쪽 덩어리가 34ms 간격으로 떠오릅니다(`@starting-style`, 모르는 브라우저는 즉시 표시). 만들어 넣은 손잡이에는 왼쪽부터 차오르는 밑줄이 있습니다.
  목차·검색·`#` 링크·`scrollIntoView`로 접힌 덩어리 안을 가리키면 그 덩어리가 먼저 펼쳐집니다. 적용: 상담 대화 연습장, 노동시장 산책, DACUM(용어 사전·보조 목록·비교표), 이론 위키(상세 창), 실무 가이드(법령 용어 번역기), 환승노선도(역 카드 실무 팁), 서재(읽기 책상 섹션).
- **가려짐 방지**: 위에 붙어 있는 머리말·탭 줄의 높이를 재서 `html`의 `scroll-padding-top`으로 넣습니다. 항목으로 건너뛸 때(`scrollIntoView`, `#` 링크) 제목이 그 밑에 가려지지 않습니다.
- **글자 대비**: 보조 글자색 `--dim`은 밝은 테마 `#6e645b`(바탕 대비 5.4:1)입니다. 4.5:1 아래로 옅게 쓰지 않습니다. 가장 작은 글자는 11px 이상, 그림·책등 장식 글자도 8.5px 이상으로 둡니다.
- **그림 속 글자**: 글자 뒤 테두리(halo)는 `paint-order`를 SVG 속성이 아니라 CSS(`style="paint-order:stroke fill"`)로 줍니다. 속성으로 주면 아이폰 사파리에서 무시되어 테두리가 글자를 덮습니다.
