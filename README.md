# 직업상담 통합 자료실

직업상담 이론, 심리검사 해석, 직무분석, 국민취업지원제도 실무, 미래고용 보고서, 학과·직업 연결 지도를 익히기 위한 학습·업무 보조 자료 사이트입니다.

사이트 주소: https://ccttsi.github.io/jobcounsel/

### 다시 읽는 『직업의 선택』 데이터

`/parsons/data/book.json`의 `chapters[]` 순서대로 장 파일을 읽습니다. 장을 더하려면 `{"id","cards":[...]}` 파일을 만들고 `chapters[]`에 한 줄 더합니다. 카드 종류는 `cover`·`text`·`quote`·`figure`·`table`·`chips`·`pairs`·`now`·`ask`·`source`이며, 본문의 `[[키]]`는 `glossary.json`의 옛 말 → 오늘의 말 띄움, `**굵게**`는 강조입니다. 카드 한 장은 공백 포함 200자 이내로 씁니다.

로그인하지 않아도 모든 기능을 쓸 수 있습니다. 로그인은 학습 기록을 저장·동기화하기 위한 선택 기능입니다.

### 환승노선도 데이터

`/transit/data/transit.json` 한 파일을 화면이 그대로 읽습니다. 출발 유형(`types`), 역량 번역(`assets`), 환승역(`stations`, 단기 `t1`·중기 `t2`·장기 `t3`), 종착역(`dests`)으로 나뉩니다. 역을 더하거나 고칠 때는 이 파일만 바꾸면 됩니다. 제도 수치는 `checked` 날짜 기준이며 해마다 다시 확인합니다. 사용자가 입력한 내용은 브라우저(`jc-transit`)에만 저장하고 연동하지 않습니다.


### 노동시장 산책 데이터

화면(`/labor/index.html`)과 엔진(`/labor/app.js`)은 데이터를 고치지 않고 `/labor/data/` 두 파일을 읽습니다. `concepts.json`은 갈래(`groups`)·개념(`concepts`, 대학원 수준은 `deep: true` → 「깊이 보기」 표시, 그래프는 `widget` 이름)·실업 사례(`unempCases`)·바탕 이론(`sources`), `news.json`은 최근 공식 수치(`latest`, `checked` 날짜 기준)·지표 사전(`indicators`, 찾기 규칙 `re`)·표현 함정(`patterns`)·연습용 가상 기사(`samples`)·확인처(`where`)입니다. 고용동향이 새로 나오면 `latest`와 `checked`만 바꾸면 됩니다. 붙여 넣은 기사 문장은 저장·전송하지 않습니다.

### 자격증 도감 데이터

화면(`/cert/index.html`)과 엔진(`/cert/app.js`)은 데이터를 고치지 않고 `/cert/data/certifications.json`(certifications-wiki v1.0.0, 830건: 국가기술자격 513 · 국가전문자격(면허 포함) 212 · 국가공인 민간자격 101 · 국가주관 능력검정 4)을 읽습니다. 구조·출처·채움 현황·한계는 `cert/data/README.md`에 있습니다.

- 주소: `#list?c=KT&g=기사&f=3&mo=5&m=…&a=…&has=1&q=…&p=2`(찾기), `#KT-0269`(한 건), `#about`(출처와 한계). 조건은 주소에만 남고 저장·전송하지 않습니다.
- **값이 null이거나 빈 항목은 줄을 만들지 않고 뺍니다.** 뺀 항목 이름은 상세 맨 아래 「미표기 항목(…)은 공공데이터·법령상 공식 근거가 확인되지 않은 정보이므로, 시행기관 공식 안내를 확인해 주세요.」 문장에만 모으고 `official_url`(+`official_urls`)로 잇습니다.
- 화면에서만 만드는 값: 시행 월(`typical_months` 문자열 → 단계별 12칸), 연간 시행 횟수 묶음(1회 이하·2·3·4회 이상), 시행처 표기 다듬기(앞의 `: `, 뒤의 `(www…)`), 국가기술자격 등급 사다리(이름 끝 기술사·기능장·기사·산업기사·기능사를 떼어 같은 종목끼리 묶음).
- 관련 직업(`related_jobs`)은 `../decalcomania/#J-…`로 잇습니다.
- 화면 구성(PR #41): 목록은 5·10·20개씩(`jc-cert-per`), 휴대폰 조건은 아래에서 올라오는 시트, 조건 묶음은 접고 펴기. 상세는 자격증 카드 + 「한눈에」 칸(시행·단계·과목 수·합격선, 누르면 해당 탭) → 탭(시험·일정·소개·연결). 시험 탭은 단계(필기·실기·면접…)를 눌러 과목 칩·방식 꼬리표·합격선 막대를 본다. 긴 글은 세 줄 + 「더 읽기」, 진출처는 칩.
- 서술 필드의 띄어쓰기 끊김은 `cert/data/README.md` 맨 위 설명대로 보정했습니다.
- 새 데이터가 나오면 `certifications.json`만 바꾸면 화면의 숫자가 따라옵니다.

### 집중 보기와 공통 디자인 (`assets/prefs.js`)

모든 페이지는 머리말의 `<span data-jc-prefs></span>`와 `</body>` 앞의 `prefs.js`만으로 아래 기능을 물려받습니다. 새 꼭지도 본문을 `<main>`에 담고 이 두 줄을 넣으면 됩니다.

- **집중 보기**: 버튼을 누르면 본문(`[data-jc-content]` → `main` → `[role=main]` → `#main` → `#app`)과 그 조상만 남기고 머리말·메뉴·옆 목록·바닥글을 숨겨 본문을 화면 가득(100dvh) 띄웁니다. 되는 기기에서는 Fullscreen API를 함께 켭니다. Esc나 떠 있는 도구함으로 끝냅니다.
- **떠 있는 도구함**: 집중 보기 중 오른쪽 아래에 연하게 떠 있다가, 마우스가 가까이 가거나 손으로 누르면 또렷해집니다(집중 보기 끝내기·테마·글자 크기). 바깥을 누르거나 3.6초 동안 조작이 없으면 다시 연해집니다. 형광펜 도구함 버튼도 함께 연해집니다.
- **페이지별 조정**: `window.JC_IMMERSIVE = { content, hide, keep, fullscreen }`. 화면을 다시 그리는 요소는 페이지 CSS에서 `html[data-jc-imm] .toc{display:none}`처럼 숨깁니다(예: `/labor/`, `/library/`). 버튼 하나만 둘 때는 `<span data-jc-prefs="immersive"></span>`(서재 읽기 책상).
- **공통 디자인 층**: 종이 결 바탕, 읽은 만큼 차는 색띠(형광펜 다섯 색), 제목 줄바꿈 고르기, 세피아 종이 색, 집중 보기의 교정지 재단선. 모두 `@layer` 안에 있어 페이지 자체 스타일이 이깁니다. 움직임은 `transform`·`opacity`만 쓰고 `prefers-reduced-motion`과 집중 보기에서는 멈춥니다. 끄려면 `window.JC_DESIGN = { grain: false, progress: false }`.
- **손맛 층**(2026-11-15 보강): 위쪽 눈금·색띠(스크롤을 rAF로 묶어 `scaleX`만 바꿔 아이폰 사파리에서도 동작), 머리말 아래 어긋난 2톤 인쇄선, 제목 옆 소인, 눌리는 카드(`.jc-pop` — 본문 안의 큼직한 링크·버튼을 실행 중에 찾아 오프셋 그림자와 들림·눌림을 단다), 새로 들어온 덩어리의 등장 모션(`.jc-in`). 집중 보기에서는 모두 빠집니다. 주기적으로 다시 그리는 곳에는 `data-jc-still`을 답니다.
- **떠 있는 것은 본문을 가리지 않게**: 집중 보기 도구는 맨 아래 줄의 작은 손잡이 하나로 쉬다가 누를 때만 옆으로 펼쳐집니다. 형광펜 버튼은 손가락으로 쓰는 화면에서 쉬는 동안 오른쪽 가장자리로 반쯤 물러납니다.
- **접어 두기(공용)**: `window.JC_FOLD = [{ box, head | title, on, open } | { head }]`. 휴대폰(900px 미만)에서 상세를 접어 두고 제목을 누르면 펼칩니다. DOM 구조는 바꾸지 않고 클래스·속성만 답니다(상담 대화 연습장, 노동시장 산책에서 사용). DACUM은 모듈을 한 번에 하나씩 보이고, 국취 매뉴얼 항목 카드는 `<details>`로 접습니다.
  목차·검색·`#` 링크·`scrollIntoView`로 접힌 덩어리 안을 가리키면 그 덩어리가 먼저 펼쳐집니다. 적용: 상담 대화 연습장, 노동시장 산책, DACUM(용어 사전·보조 목록·비교표), 이론 위키(상세 창), 국취 매뉴얼(공문서 번역기), 환승노선도(역 카드 실무 팁), 서재(읽기 책상 섹션).
- **가려짐 방지**: 위에 붙어 있는 머리말·탭 줄의 높이를 재서 `html`의 `scroll-padding-top`으로 넣습니다. 항목으로 건너뛸 때(`scrollIntoView`, `#` 링크) 제목이 그 밑에 가려지지 않습니다.
- **글자 대비**: 보조 글자색 `--dim`은 밝은 테마 `#6e645b`(바탕 대비 5.4:1)입니다. 4.5:1 아래로 옅게 쓰지 않습니다. 가장 작은 글자는 11px 이상, 그림·책등 장식 글자도 8.5px 이상으로 둡니다.
- **그림 속 글자**: 글자 뒤 테두리(halo)는 `paint-order`를 SVG 속성이 아니라 CSS(`style="paint-order:stroke fill"`)로 줍니다. 속성으로 주면 아이폰 사파리에서 무시되어 테두리가 글자를 덮습니다.
- 세피아는 밝은 테마 위에 종이 색을 얹는 방식이라 저장 값은 `jc-theme = light`, `jc-tone = sepia`입니다.

- `/vpi/`: 직업선호도검사의 문항·규준·결과해석 자료는 한국고용정보원 저작물이며 싣지 않습니다.
