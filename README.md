# 직업상담 자료실

직업상담 이론, 심리검사 해석, 직무분석, 국민취업지원제도 실무를 익히기 위한 학습·업무 보조 자료 사이트입니다.

사이트 주소: https://ccttsi.github.io/jobcounsel/

## 구성

| 주소 | 페이지 |
|---|---|
| `/` | 첫 화면(목차) |
| `/theory/` | 직업상담 이론 위키 |
| `/vpi/` | 직업선호도검사 L형 해석 시뮬레이터 |
| `/dacum/` | DACUM 마스터 아키텍처 |
| `/manual/` | 2026 국취 매뉴얼 하이퍼위키 |
| `/hud/` | 2026 국취 상담 HUD |

각 페이지는 폴더 안의 `index.html` 한 파일로 되어 있고, 빌드 과정 없이 그대로 게시됩니다.

## 유의 사항

이 사이트의 자료는 AI의 도움을 받아 만든 비공식 자료입니다. 고용노동부, 한국고용정보원 등 어떤 기관의 공식 자료도 아닙니다. 실제 업무 판단은 공식 매뉴얼 원문과 지침으로 확인하십시오.
