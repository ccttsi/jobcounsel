# 직업상담 통합 자료실

직업상담 이론, 심리검사 해석, 직무분석, 국민취업지원제도 실무, 미래고용 보고서, 학과·직업 연결 지도를 익히기 위한 학습·업무 보조 자료 사이트입니다.

사이트 주소: https://ccttsi.github.io/jobcounsel/

## 구성

| 주소 | 페이지 |
|---|---|
| `/` | 첫 화면(목차) |
| `/theory/` | 직업상담 이론 위키 |
| `/vpi/` | 직업선호도검사 L형 해석 시뮬레이터 |
| `/dacum/` | DACUM 마스터 아키텍처 |
| `/manual/` | 2026 국취 매뉴얼 하이퍼위키 |
| `/hud/` | 2026 국취 상담 HUD |
| `/library/` | 국회 미래고용 디지털 서재 |
| `/decalcomania/` | 커리어데칼코마니 (학과 ↔ 직업 거울 지도) |
| `/assets/marker.js` | 공용 형광펜·포스트잇 도구함 |
| `/assets/sync.js` | 로그인·기기 간 연동 (선택 기능) |

각 페이지는 폴더 안의 `index.html` 한 파일로 되어 있고, 빌드 과정 없이 그대로 게시됩니다.

로그인하지 않아도 모든 기능을 쓸 수 있습니다. 로그인은 학습 기록을 저장·동기화하기 위한 선택 기능입니다.

### 커리어데칼코마니 데이터

`/decalcomania/data/`의 세 파일을 뷰어가 그대로 읽습니다. 같은 스키마의 새 파일로 바꾸면 화면이 그대로 따라옵니다. 스키마·아이디 체계·출처·한계는 `decalcomania/data/README.md`에 있습니다.

| 파일 | 내용 |
|---|---|
| `majors.json` | 표준학과 501(`D-…`), 대학 412(`U…`), 대학별 학과 개설 24,528(`DP…`) |
| `jobs.json` | 직업 552(`J-…`), 한국고용직업분류 2025 트리, 대분류 묶음(`JG-…`) |
| `edges.json` | 학과 → 직업 관계 6,769 (면허필수·전공우대·관련전공·전공무관·진출통계) |

## 유의 사항

이 사이트의 자료는 정답이 아닌 참고·실습용 도구이며, AI의 도움을 받아 만든 비공식 자료입니다. 고용노동부, 한국고용정보원 등 어떤 기관의 공식 자료도 아닙니다. 실제 업무 판단은 공식 매뉴얼 원문과 지침으로 확인하십시오.
