# FTN-1 문답집 — 재료 수집·시험용 분리 (2026-11-28 · 인스팅트)

> MCL Goal · FTN(진짜 파인튜닝) 하부계획 FTN-1. 학습 후보를 저장소 안 재료에서 정형화해 모으고,
> 시험(test) 문항과의 2-gram 겹침을 검사한다. 기준 문서: 노션 「FTN — 진짜 파인튜닝 하부계획」.
> 역할 재조정(2026-11-28): 재료 정형화·데이터 카드·검사는 인스팅트 몫(노션 MCL Goal §5).

## 1. 모양 — «근거를 보고 답하는» 학습

```
입력  = 지침 요약 + 근거 조각(AUP-3 chunks) + 질문
출력  = 모범 답
```

- 근거 없이 질문만 넣는 학습은 하지 않는다 — 사실을 지어내는 모델이 된다.
- 이 폴더의 스크립트는 «입력» 쪽 재료(질문 + 근거 참조)만 모은다. **모범 답은 여기서 만들지 않는다.**
  모범 답은 ① AUP 비서 초안 → ② 클로드 근거·수치 대조(AUP-5 검사기 통과 필수) →
  ③ 피클 현장 말투 점검 → ④ 태화님 무작위 10% 눈 검수 를 거쳐 붙는다. 통과분만 train.
- 섞는 비율(초안): 설명 30 · 계산 15 · 자료 안내 25 · 상담 진행 15 · 거절 15.
  실제 비율은 AUP-2 점수가 낮은 유형 쪽으로 기울인다. 후보의 `style` 칸이 이 배분의 재료다.

## 2. 스크립트

```
python3 ops/ftn/collect.py              # 후보 만들기 → ops/ftn/dataset/candidates.jsonl
python3 ops/ftn/collect.py --check      # 원천 동기 확인(CI)
python3 ops/ftn/overlap_check.py        # 시험 문항과 2-gram 겹침 검사
python3 ops/ftn/overlap_check.py --self-test
```

- `collect.py` — 재료에서 후보를 뽑아 `witw-ftn-candidates/1.0.0` 한 줄 한 건(jsonl)으로 쓴다.
  결정적(같은 입력이면 같은 출력). 근거는 조각 본문이 아니라 참조(`i`·`s`·`src`·`as_of`)만 —
  본문은 답 초안 단계에서 푼다. 모델 호출 0, 네트워크 0.
- `overlap_check.py` — 시험 문항(split=test 전체, q+ctx) 낱낱과 글자 수준 2-gram을 비교한다.
  · exact — 정규화한 문장이 똑같다 → 실패
  · near — 한 시험 문항과의 겹침 비율 0.6 이상 → 실패(«근소한 변형»)
  · shared — 0.6 미만의 겹침 → 기록만(법정 용어는 자연스레 겹친다)
  판정은 **한 시험 문항과의 비교**다 — 전체를 합친 풀과 비교하면 흔한 어미가 여러 문항에
  흩어져 오탐이 된다(2026-11-28 시행착오 기록: 풀 비교에서 137건 중 61건 오탐 → 낱개 비교로 0건).
  글자 수준 2-gram을 쓰는 이유: 낱말 수준은 «얼마→얼마예요» 같은 어미 변형을 놓친다.
- 두 검사 모두 `validate_repo.py`(검사 항목 `ftn`, json과 함께 돈다)에 연결돼 있다.
