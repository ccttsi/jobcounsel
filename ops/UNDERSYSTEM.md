# 언더시스템 — 모든 섹터 밑에서 도는 공통 장치

화면을 새로 그리는 층이 아니라, 섹터가 **끊겨도 죽지 않고 · 두 번째부터 바로 열리고 · 고장을 먼저 알게** 하는 바닥 층이다.
섹터 코드는 이 층을 몰라도 된다(자료는 평소처럼 `fetch('./data/x.json')`). 일지는 노션 보드 「언더시스템 구축」과 Drive 「02 · 언더시스템 구축 일지」에 체크포인트마다 남긴다.

## 섹터가 지킬 것

- `<head>`의 `<meta charset>` 바로 아래에 **defer 없이** `<script src="../assets/core.js"></script>` (대문은 `./assets/core.js`). 다른 스크립트보다 먼저 실행돼야 자료 요청을 빠짐없이 지킨다.
- 자료를 못 받았을 때 섹터가 쓰던 안내 문구는 그대로 둔다. 「다시 시도」 단추는 섹터마다 만들지 않는다 — 공통 띠가 맡는다.
- 섹터가 직접 알릴 일이 있으면 `JCCore.notice('문장입니다.', '단추 이름', fn)`, 닫을 땐 `JCCore.clear()`. 문장은 「~입니다」체.
- 화면 조각(`#jc-core`)은 그림자 DOM이라 섹터 CSS와 섞이지 않는다. 움직임은 `transform`·`opacity`뿐이고, 집중 보기·움직임 줄이기에서는 멈춘다.
- 404(파일 없음)는 다시 받지 않는다. 있어도 되고 없어도 되는 자료는 섹터가 스스로 판단한다.
