## 3. 제약 — 지키지 못하면 그 자체로 실패다

- [ ] **저작권**: 모든 자료에 라이선스 표기. `PRESS`·`KOGL-NONE`·`FACTS-ONLY`·미확인은 **Track B**(사실·수치만 새로 씀, 인용 15단어 이내). 재가공 허용 자료만 Track A.
- [ ] **내보내기 금지**: 저장·인쇄·PDF·복사·오프라인 보관 장치를 만들지 않는다.
- [ ] **미확인 값**: 지어내지 않는다. 확인되지 않으면 항목째 생략하고 공식 출처를 적는다.
- [ ] **화면 분량**: 큰 화면 ≤ 1.5화면, 휴대폰 ≤ 2.5화면(긴 글 읽기 화면은 예외로 적는다).
- [ ] **모션**: `transform`·`opacity`만. 60fps(권장 144fps), 방치 모션 규칙은 `DESIGN.md`를 따른다.
- [ ] **터치**: 누르는 것은 44×44px 이상.
- [ ] **정렬**: 시스템 요소(닫기·탭·이전/다음)는 정중앙, 내용 박스는 테두리에 붙지 않게. 글자 시작점 편차 **0.00px**.
- [ ] **문체**: 「~입니다」체. 유머 문구·미사여구 없음.

## 5. 실패하면 멈춘다 (중단 조건)

- 위 숫자 중 하나라도 기준을 넘고, 원인을 모른 채 「일단 머지」하려 할 때
- 스키마를 깨는 변경이 필요한데 `*/SCHEMA.md`를 아직 못 고쳤을 때
- 라이선스가 확인되지 않은 자료를 화면에 올려야 할 때 (→ 항목을 빼고 출처만 남긴다)
- 다른 세션이 같은 파일을 잡고 있을 때 (→ 파일을 나누거나 순서를 정한다)
