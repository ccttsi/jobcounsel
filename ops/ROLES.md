# 역할 분리 헌장 (운영 허브 원본)

> **최상위 규범: [`CONSTITUTION.md`](../CONSTITUTION.md)** — 이 헌장보다 앞이다. 누가 무엇을 하기 전에, 여섯 조항(저작권·지재권 / 사실·시행일 / 유출·개인정보 / 유기적 연결 / 심미성·성능 / 기록·자기검증)과 §7 자가검증 체크리스트를 먼저 지킨다. 어떤 주체(클로드 세션·클로드 예약 작업·피클·Make·사람)도 헌법을 어긴 작업을 이어 가지 않는다.
>
> 이 파일이 **원본**이다. 노션 「🧭 운영 허브 · 역할 분리 헌장」과 Drive 「00 · 이 창고의 역할」, Make 시나리오 설명, Supabase 테이블 설명, 예약 작업 프롬프트는 모두 이 파일을 가리키는 사본·요약이다. 어긋나면 이 파일이 기준이고, 바꿀 때는 여기부터 고친 뒤 사본을 맞춘다.
> 모든 세션(Claude Code·예약 작업·피클·채팅)은 일을 시작하기 전에 이 헌장을 먼저 읽는다. 이 저장소에서 여는 Claude Code 세션은 SessionStart 훅이 요약을 자동으로 보여 준다.

## 한 줄 원칙

클로드는 **설계·코드 개발·저장소 관리**에 집중한다. 반복 수집·저장·DB 실행·화면 검수는 연결 툴로 **직접** 처리하고, 태화님에게 수동 복사·확인을 넘기지 않는다. 툴로 할 수 없는 일(계정 연결 첫 승인처럼 보안상 본인 클릭이 필요한 것)만 링크 하나와 누를 곳만 짧게 요청한다.

## Make ↔ 무료 팀원 분업 — 크레딧은 지키고 일은 나눈다 (2026-11-22 태화님 지시)

**Make의 무료 한도는 월 1,000 오퍼레이션이다.** 오퍼레이션은 시나리오가 **모듈(스텝) 하나를 지날 때마다 1회**로 세어지므로, 5스텝짜리 시나리오는 한 번 돌 때마다 5회가 빠진다(하루 세 번이면 15회 — 두 달이면 1,000회가 바닥난다). 그래서 **Make는 «바깥 변화를 알아채고 전표를 넘기는» 1~2스텝만** 맡고, 무거운 일은 한도가 없거나 훨씬 넉넉한 무료 팀원에게 넘긴다. 이 절이 그 경계의 원본이고, 주소·한도·키 보관 위치는 [`CONNECTORS.md`](CONNECTORS.md)에 있다.

### 1. 단계별 담당 — 누가 무엇을 들고 가는가

| 단계 | 맡는 팀원 | 하는 일 | 다음 단계로 넘기는 것 |
|---|---|---|---|
| ① 바깥 변화 감지 | **Make** (1~2스텝) | RSS·Gmail·노션 변화를 주기마다 확인해 **주소·제목·날짜만** 뽑는다 | 원문 주소 한 줄 |
| ② 본문 추출 1차 | **Jina Reader** (`r.jina.ai`) | 광고·메뉴를 걷어 낸 Markdown 본문. 키 없이 분당 20회 | Markdown 본문 |
| ③ 본문 추출 2차(폴백) | **Firecrawl** | Jina가 실패한 것만 — JS로 그려지는 지면·PDF. **월 1,000페이지 중 200 비축 · 하루 25페이지 하드캡** | 같은 Markdown |
| ③-보조 대량 수확 | **Crawl4AI** | 수백 쪽을 한 번에 긁어야 할 때 Colab·PC에서 직접(오픈소스·계정 없음) | 파일 묶음 |
| ④ 3줄 요약·카테고리 초안 | **Groq** | 수집분의 초안 요약·태그 후보. 무료 일 1,000회 | 초안(사실 아님) |
| ⑤ 사실·저작권 검수 | **클로드·피클 + `collect_gate.py`** | Track A/B 판정, 시행일·출처·15단어 규칙, 초안 숫자를 원문과 대조 | 통과한 항목만 |
| ⑥ 가공·검증·빌드·배포 | **GitHub Actions** | `validate_repo.py`·스모크·`shared_ui_probe.py`·Pages 배포. 공개 저장소는 무제한 | 라이브 |
| ⑦ 학습·임베딩 배치 | **Kaggle**(주 30시간 · 6시간 비축) · **Colab**(짧은 실험) | 분류기 재학습·임베딩 생성 | 모델·색인 파일 |
| ⑧ 매장 앞단 | **Cloudflare** (Turnstile · Workers AI · Vectorize) | 봇 차단은 로그인·비서·폼 앞단에만 건다. **Bot Fight Mode 전역 차단은 끈다** — 피클·Actions·수집기가 봇으로 막히면 안 된다 | — |
| ⑨ 캐시·2단 저장 | **Upstash Redis**(250MB) · **Neon Postgres** | 자주 읽는 것만 캐시하고, 지난 기록·통계·MLC 원천 로그는 Neon으로 옮긴다. Supabase 500MB에는 활성 데이터만 | — |

- **추출이 세 번 실패하면 그 항목은 생략한다**(헌법 2-1). 본문 대신 출처 URL·기준일만 남기고, 빈 칸·「확인 중」으로 채우지 않는다.
- **Make 안에서는 루프를 돌리지 않는다.** 20건을 도는 루프는 오퍼레이션 20회다 — Make는 «1건 감지»까지만 하고 나머지는 Actions가 맡는다.

### 2. Make가 하지 않는 것

- **무거운 HTML 파싱·정규식 반복·장문 AI 가공**(요약 프롬프트·번역·태깅) — 본문은 Jina→Firecrawl, 초안은 Groq 몫.
- **배치 학습·임베딩** — Kaggle·Colab 몫.
- **라이선스 판정** — 사람·클로드·`collect_gate.py` 몫. Make는 재가공 허용이 확인된 출처만 받는다.
- **화면 코드에 같은 수집을 넣기** — 정적 앱은 `data/*.json`을 읽기만 한다.

### 6. 연결은 GitHub 한 곳, 앞단만 Cloudflare 직통

- **GitHub(`ccttsi/jobcounsel`)가 중앙 허브다.** 수집·학습·보관(Jina·Firecrawl·Crawl4AI·Kaggle·Colab·Neon 백업)은 서로 직접 잇지 않고 **GitHub와 GitHub Actions를 통해서만** 오간다. 서비스끼리 거미줄처럼 다 이을 필요가 없다.
- **실시간이 필요한 앞단만 Cloudflare 환경변수에 키를 꽂는다** — Turnstile·Workers AI·Upstash·Groq.
