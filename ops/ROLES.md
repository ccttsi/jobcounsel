# 역할 분리 헌장 (운영 허브 원본)

> 이 파일이 **원본**이다. 노션 「🧭 운영 허브 · 역할 분리 헌장」과 Drive 「00 · 이 창고의 역할」, Make 시나리오 설명, Supabase 테이블 설명, 예약 작업 프롬프트는 모두 이 파일을 가리키는 사본·요약이다. 어긋나면 이 파일이 기준이고, 바꿀 때는 여기부터 고친 뒤 사본을 맞춘다.
> 모든 세션(Claude Code·예약 작업·피클·채팅)은 일을 시작하기 전에 이 헌장을 먼저 읽는다. 이 저장소에서 여는 Claude Code 세션은 SessionStart 훅이 요약을 자동으로 보여 준다.

## 한 줄 원칙

클로드는 **설계·코드 개발·저장소 관리**에 집중한다. 반복 수집·저장·DB 실행·화면 검수는 연결 툴로 **직접** 처리하고, 태화님에게 수동 복사·확인을 넘기지 않는다. 툴로 할 수 없는 일(계정 연결 첫 승인처럼 보안상 본인 클릭이 필요한 것)만 링크 하나와 누를 곳만 짧게 요청한다.

## 누가 무엇을 하나

| 주체 | 한다 | 하지 않는다 |
|---|---|---|
| 태화님 | 방향 결정, 실기기 확인, 계정 연결 첫 승인 | 파일 복사·SQL 복붙·화면 검수 같은 반복 작업 |
| 클로드(Claude Code) | 설계·코드·저장소(커밋·PR·머지), 검수 통과 뒤 보고, 노션 보드·개발일지 기록 | 화면 코드 안에 외부 수집·API 호출 넣기, 스키마에 없는 값 만들기 |
| 피클 | **기획·작업 준비 파트너**: 태화님과 대화하며 바이브 코딩으로 기획을 다듬고, 노션 섹터 보드에 「n번 작업 지시」(스펙·경로·제약·데이터 계약)까지 준비한다. **데일리 뉴스를 노션에 업로드**한다(기존에 등록된 브리핑 데이터 스케줄 `briefing/data/*.json`도 피클 담당, 스키마 문서 먼저 갱신) | 화면 코드 작성, 클로드의 구현 판단 대신하기 |
| Make | **정기 크롤링 전담**: ① 월·목 07:00 디자인 글 RSS → 노션 🎨 디자인 학습함 ② 갱신되는 공공데이터(직업상담·고용시장·AI와 상담 업무 관련 주제) → 노션 📊 자료 수집함. **재가공·재게시가 허용된 범위**(공공누리 1유형·퍼블릭 도메인·CC BY·무료 공공데이터 이용허락)만 수집하고 라이선스를 항목마다 기록 | 데일리 뉴스(피클 담당), 라이선스 불명·언론 기사 본문 수집, 화면 코드 |
| 클로드 예약 작업(월·목 08:41) | 학습함 소화 → 🧠 클로드 소화 노트, 목요일 공식 통계 보충 → 📊 자료 수집함 | 저장소·코드 수정 |

## 연결 툴별 역할

| 툴 | 역할 | 클로드가 하는 방식 | 하지 않는 것 |
|---|---|---|---|
| **Notion** | 기획·기억 | 시작 때 섹터 보드·DESIGN·소화 노트를 읽고(`/start`), 끝나면 보드 상태와 개발일지 3줄을 직접 갱신(`/finish`) | 규칙의 원본 두기(원본은 저장소) |
| **Make** | 외부 정기 크롤링(디자인 RSS + 재가공 허용 공공데이터) | 시나리오를 직접 만들고 시험·수정, 무료 한도(월 1,000크레딧) 안에서 주기 설계, 결과는 노션 학습함·자료 수집함으로 | 정적 앱 코드에 같은 수집을 넣기, 라이선스 불명 자료 수집 |
| **Google Drive·Sheets** | 원자료 창고 | 「직업상담 자료실 · 원자료 창고」 폴더에서 CSV·표·문서를 직접 읽어 `data/*.json`으로 변환, 「01 · 원자료 색인」 시트에 변환 기록 | 채팅으로 파일 재전송 요청, 사이트가 Drive를 직접 읽게 하기 |
| **Supabase** | 선택 로그인·연동·익명 통계 | 테이블 조회·통계 점검·마이그레이션·시험 행 정리를 도구로 직접 실행하고 결과 확인(적용 전 구조 조회) | SQL 복붙 실행 요청, 개인 식별 정보 저장 |
| **Playwright** | 실화면 검수 | 구현·수정 뒤 휴대폰(390)·태블릿·데스크톱에서 콘솔 오류 0·가로 넘침 0·44px·화면 분량·버튼·모션 실측. 공용 스크립트 `ops/qa/audit.js` | 검수 없이 PR·완료 보고, 시험용 가짜 데이터를 저장소에 넣기 |
| **GitHub** | 원본 저장소·배포 | 브랜치 → 커밋 → PR → 머지 → Pages 배포 확인 | 다른 세션이 진행 중인 브랜치의 파일 수정 |

## 화면을 만들 때 꼭 지킬 것 (요약 — 상세는 CLAUDE.md·DESIGN.md)

- 지재권 최우선(DESIGN §0), 내보내기(저장·인쇄·PDF·복사) 금지, 확인 안 된 값은 항목째 생략
- **무의미한 세로 스크롤 금지**: 큰 화면 ≤ 1.5화면, 휴대폰 ≤ 2.5화면. 다단·목록+한 장·탭·시트로 화면을 적극적으로 쓴다
- 모션은 transform·opacity만, 터치 44px, 90:10, 유머 문구 금지
