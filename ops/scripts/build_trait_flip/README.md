# 장점 ↔ 단점 뒤집기 어휘 만들기 (`trait-flip`)

`trait-flip/data/traits.json`은 손으로 고치는 파일이 아니라 **여기서 만들어 내는 산출물**이다.
낱말과 문장 조각은 `src/*.tsv`에 적혀 있고, `build.py`가 그것을 읽어 낱말·전환 짝·카드 문장을
만들어 `traits.json` 한 파일로 내보낸다. (2026-11-24, 98개 → 506개 확장)

```bash
python3 ops/scripts/build_trait_flip/build.py
```

- `trait-flip/data/traits.json`을 읽어, 이 원본에서 만든 낱말은 먼저 걷어 낸 뒤 다시 만든다.
  같은 원본으로 두 번 돌려도 결과가 같다(멱등). 손으로 쓴 기존 98개 낱말·184짝은 건드리지 않는다.
- 결과: 낱말 506(단점 255 · 장점 251) · 전환 짝 913 · 카드 1,826장 · 비슷한 말 1,712개.

## 원본 형식 (`src/*.tsv`)

묶음(분야) 하나가 파일 하나다. 줄은 `|`로 나누고, 한 줄이 낱말 하나다.

- 단점 `W`: `W|id|낱말|한 줄 설명|장면|비용|보완 습관|결과|행동 꼴(;) |축(,)|인기|비슷한 말(;)`
- 장점 `S`: `S|id|낱말|한 줄 설명|강점 기제|지나칠 때 그늘|구체 방법|축(,)|인기|비슷한 말(;)`

- **장면·비용·보완 습관·결과**는 카드의 «자소서 한 줄»과 방어 3단을 만들 때 쓰는 조각이다.
  비용은 «무엇이 잘못되는지», 보완 습관은 «지금 어떻게 바꿨는지», 결과는 «그래서 무엇이 달라졌는지».
- **축(axis)** 은 «어떤 낱말과 뒤집히는가»를 정하는 표지다. 단점과 장점이 축을 하나라도 나누면
  짝이 될 수 있고, 드문 축(예: `boundary`·`secret`)일수록 더 정확한 짝으로 먼저 뽑힌다.
- **인기(1/0)** 는 첫 화면 인기 칩에 올릴 낱말.
- **행동 꼴**은 «…하는/…한»처럼 사람을 꾸미는 꼴로 적는다(«…한다»로 적으면 카드 머리말이
  «…한다 사람»이 된다). 서술형으로 적은 것이 있으면 `stems.json`에 `서술형|꾸밈형` 한 줄을 더한다 —
  빌드가 그 표를 보고 바꿔 준다(2026-11-24, 186개를 이 표로 바로잡았다).

## 짝 짓기와 문장 조립

1. 각 단점은 **3갈래**를 기본으로 잡고, 축이 잘 맞는 장점이 남아 있으면 **4갈래**까지 더한다
   (장점은 4갈래를 넘기지 않는다 — 휴대폰에서 카드가 4장을 넘으면 화면 분량 2.5가 넘는다).
2. 짝의 문장은 조각을 틀에 맞춰 잇는다: 논리 5가지 · 자소서 한 줄 3가지 · 주의 3가지 틀을
   갈래 순서대로 돌려 쓰므로 한 낱말의 카드들이 같은 문장으로 겹치지 않는다.
3. 그래서 **낱말·설명·조각은 사람이 쓰고, 카드 문장은 그 조각을 이어 붙인 결과**다.
   문장 틀 자체를 고치면 전체 카드가 함께 바뀐다(`build.py`의 `make_text`).

## 짝 고정 (`seeds.txt`)

축(axis)만 보고 고르면 «같은 분야»인데 뒤집기로는 안 읽히는 짝이 생긴다(2026-11-25 전수 검수에서
908쌍 가운데 331쌍이 «느슨함» 판정). 그런 낱말은 `seeds.txt`에 «단점id|장점id» 줄로 짝을 적어 둔다.

- `build.py`는 `src/*.tsv`보다 **먼저** 이 짝들을 놓고, 모자란 갈래만 축 순위로 채운다.
  그래서 고정한 짝은 그대로 남고, 같은 낱말의 나머지 카드는 예전 규칙대로 만들어진다.
- 손으로 쓴 기존 98개 낱말은 조각(core·how)이 없어 새 카드를 만들 수 없다 — 그런 줄은 건너뛴다.
- 짝을 고칠 때는 이 파일만 고치고 다시 빌드한다(낱말·조각은 그대로).

## 문장 틀 (2026-11-25)

한 카드 안에서 같은 말이 되풀이되지 않게 칸마다 맡는 말을 나눴다.

- **머리(wk)**: 낱말마다 적어 둔 행동 꼴이 모자라면 «…소리를 듣지만 …하는 사람»으로 낱말을
  두 번 말하던 것을, «「…」는 말을 자주 듣는 사람 / …에서 들은 사람» 세 가지로 바꿨다.
- **위험(risk)**: «무엇이 잘못되는지»만 맡는다. 방어 1단이 같은 문장을 다시 말하지 않는다.
- **방어 3단**: ① 그 말을 들은 자리 ② 지금 바꾼 방식 ③ 그래서 달라진 것.
- **주의(warn) 3번째 틀**: «숫자로 붙인다»가 어울리지 않는 낱말이 많아 «무엇이 달라졌는지를 한 문장으로»로 바꿨다.
- **질문(q)**: 네 가지 꼴을 카드마다 돌려 쓴다.


- 낱말을 더할 때는 `validate_repo.py`의 `check_trait_flip`이 요구하는 **갈래 3~5**를 반드시 채운다.
- 장면·조각이 비면 카드가 빈 채로 나가므로, 새 낱말은 여섯 칸을 모두 채워 적는다.
